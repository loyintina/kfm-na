# KFM-NA 主题宪法（theme.md）

> **地位：KFM 主题的唯一来源。** 任何 UI 视觉决策以本文为准；本文没写的，
> 先修宪再实现，不许自由发挥。
> 底本：kfmv4 `docs/guides/card-dev.md` §10 视觉规范 + §11 组件 +
> `docs/domains/floating-card/contract.md`（久经验证的条款原样保留）；
> 2026-09-12 用户修宪拍板（C1-C3/A1-A6 全裁）翻成 NA 网格像素语境。
> 与 kfmv4 底本冲突处以本文为准（底本是 web/DOM 语境，本文是 Rust 网格语境）。

## 一、总则：网格×像素中间态

**网格布局是我们的灵魂，不能丢。** 终端是粗糙的网格字符、UI 是精致的
圆角细节——这两者在 kfmv4 和 na 里长期割裂，NA 走中间态：
像素 UI 与终端网格结合。2026-09-12 二修：设计哲学正式命名 **Hi-bit**
（高精度低像素——业界通称；Square Enix「HD-2D」、Minecraft HD/PBR
材质包是同思潮变体）：**低分辨率的骨架，高分辨率的血肉**——宏观
结构量化到格，微观渲染允许无限精致（渐变/光晕/法线/光照，未来
glyph 贴图带法线做逐格光照是字面意义的 hi-bit 终端）。

**三层视觉语言**（割裂的防线在布局层，不是锁死渲染层——反例：
光球平滑光晕飘在网格终端上从不割裂，无体系混用才割裂）：

- **布局层（咬格，不让步）**：卡片内所有元素（边框盒、行、间距、
  光标框）的位置和尺寸以终端格子（CELL_W/CELL_H）为单位，
  禁止半格漂移
- **描边层（精度自由）**：边框/光效/圆角怎么画是渲染层的事，
  不破坏布局对齐即可。默认形态：渐变用**逐格色阶**（边框每格沿
  135deg 在 c1→c2 间取色——一屏四五十列=四五十步色阶，肉眼近
  连续，便宜且是品牌语言）；圆角默认**像素切角**（角部沿格对角
  切掉，方块世界原生公民），平滑圆角描边留作特例；光晕类效果
  （光球先例）允许连续渐变
- **内容层（网格原生）**：文字/列表行按格排布，行=2 格、
  标签行=2 格（2026-09-12 真机实测修订：1 格太扁），字号走格子
  变量——双指缩放改格子尺寸，全部 UI 自动同源缩放（A5 拍板）。
  **半格网（2026-09-13 四修，用户拍板）**：布局精度统一放宽到
  **0.5 格**——位置与尺寸都取半格整数倍（如 4.5 格行高、1.5 格
  行隙）；渲染层本逐像素，网格是布局纪律不是技术限制。纪律从
  「咬整格」改「咬半格网」，0.5 以下的漂移仍禁止
- **覆盖层特许**：浮层/对话框/下拉面板这类「盖着内容出现」的层，
  允许半透明+背景虚化（毛玻璃解决的是层间可读性，不是形状语言；
  AI 浮层盖终端是标准用例）。全屏页面不透明，用不上

## 二、色彩体系

### 2.1 项目主题色（不可改，宪法级）

- 终端卡灰白、AI 对话页蓝紫、光球紫——项目主题的重要来源，永不随机

### 2.2 随机 accent（召唤即随机）

- **纳管范围**：文件树页、解析页、配置（设置）页——三个可召唤页面
  **每次召唤重新随机**；AI 页不纳入卡片体系（A6/C2 拍板）
- **生成算法**（kfmv4 `card-stack.ts _generateRandomAccents` 原样移植，
  约束区间 HSL 随机，不策展不抽板）：
  - c1 色相 = 随机 0–360°
  - c2 色相 = c1 ± 30°–120°（避开同色与正对的撞色）
  - 饱和度 = 45%–70%（双色共享）；亮度 = 50%–65%（双色共享）
- **反向重开沿用**：关闭中途再拉开（closing→opening 反向分支）必须
  沿用本次已生成的配色，禁止可见跳色（kfmv4 BAR-CARD-ACCENT-01）
- **背景固定深底**：卡片底色不随 accent——深底近黑
  （kfmv4: `rgba(20,16,32,0.92)`），颜色信息全由边框/装饰承载

### 2.3 文字

- accent 色**永不用于文字**（随机色可能落亮色区间与底色冲突）
- 白色三档：标题 `rgba(255,255,255,0.85)` / 正文 0.75 / 次级 0.5

## 三、边框体系

**框分两类（2026-09-12 三修，用户拍板；2026-09-13 五修，功能光标
颜色条款推翻重订）——装修框与功能光标，形态纪律不同源：**

- **装修框**（页环/池框/卡片框——页面的装饰骨架）：吃随机 accent
  （§2.2），规则如下各条
- **功能光标**（选中态指示框——未来的文件树滚动光标；标签栏光标
  已于 2026-09-13 八修退役，换填色标签页块，见 §四 标签栏条款）：
  **颜色跟随本卡随机 accent 双色渐变**（2026-09-13 用户拍板，推翻
  09-12「固定纯蓝永不随机」决策）——与页环同一把 135° 渐变尺同源
  采样（同一渐变框原点/分母，光标像从页环的渐变布上剪下来的），
  随召唤换装；α 仍 0.7。底色固定 `rgba(46,213,163,0.15)` 绿青
  半透明垫层（kfmv4 canvas-cursor 原样复刻）。形态为**开口框**
  （只有左边+顶线+底线，无右边），规格见 §四 标签栏条款

装修框规则：

- **左粗三边**：左边粗、其余三边细；粗细比 = 3:1（kfmv4: 左 3px 其余
  1px，NA 按格标定——A4 拍板宪法只钉相对比例）。**六修适用范围
  收窄（2026-09-13 用户拍板）**：左粗条是**选择语言的视觉载荷**——
  归可选列表行专属（下池行/下拉选项行/未来文件树行）；展示型值框
  （上池字段框）四边均匀细线，不挂左粗条（实机判「太丑」——多行
  堆叠的彩条是噪音，选择语义才是它的本职）
- **最小容量律**（2026-09-13 六修，用户拍板，所有级别装修框适用）：
  净高 **≥3 格**；内容距框缘**上下 ≥0.5 格、左右 ≥1 格**。
  适用 = 卡片体系装修框（页环/池框/三级框）；**功能光标不是容器
  不适用**（标签光标 2 格行等光标领地不受影响——§三 两类分家不变）
- **135deg 双色渐变**：c1（起点）→c2（终点），默认逐格色阶实现（§一）
- **渐变暗背景**（2026-09-14 十二修新立，用户拍板：「所有渐变框都要
  有渐变的暗背景，跟输入栏标准一样，这是样式的一部分」）：凡 135°
  双色渐变装修框（页环/池框/三级框选中态/均匀细框），内芯**不许平色
  不许白填**——统一渐变暗底：边框双色各向黑压暗（标定 t=200/255，
  ≈22% 亮度——输入栏内芯 field_bg 相对描边色的实测比例），**同一把
  135° 尺同原点同分母采样**（内芯 = 从同一块渐变布上剪下来的暗部），
  不透明写入。嵌套反转内芯同步：页环 dark(c1)→dark(c2)、池框反、
  三级框还原。无边框组件（未选中行/值框）同样吃这个暗底——框没了，
  暗底在。**唯一例外（2026-09-17 BAR-107，用户拍板「框动行不动」）：
  下池选中光标层内芯 = 半透明渐变暗底（α=0x55≈33%，标定可微调）**——
  光标是盖在行层之上的独立层，芯若不透明就逼出「文字烤进光标层」
  （平移期双画错位病根）；半透明芯让选中行文字只归行层、透芯显出，
  光标只画框。层内画字 = 违宪
- **角部形态**：默认像素切角（沿格对角切角）；平滑圆角描边为特例，
  需登记用途（§一 描边层）
- **多级嵌套逐层反转**：外壳 c1→c2 → 内卡 c2→c1（反转）→ 子卡 c1→c2
  （还原）→ 孙卡再反转。**透明度不降**——内外卡同饱和度同视觉重量
- **层级归属原则**：卡片内没有裸元素，每个可见元素归属某一层框；
  同层元素统一边框样式、统一间距

## 四、卡片骨架

- **无标题栏概念**：整张卡都是内容区；需要标题/标签等结构时，
  在首行自开布局区域实现（A3.1 拍板）
- **标签栏**（配置卡首行布局区，A3 拍板）：
  - 横滑区（内容超出可横滚）；标签点击切换池页，池类可追加
  - **选中态 = 填色标签页块**（2026-09-13 八修换案，用户拍板：开口框
    方案「还是丑」退役，参照终端标签条实证图——信箱截图
    IMG_20260913_172208；**同日十一修入随机色体系**，用户拍板）：
    - **每标签独立随机双色**（十一修新立）：每个标签各自独立走一遍
      kfmv4 约束区间随机（§2.2 同一 AccentRng 序列逐标签 generate），
      **页 accent ≡ 选中标签的双色**——点选 = 光标弹簧移过去 +
      整页（页环/双池/下拉/跳框/底线）**瞬时**换成该标签双色
      （无过渡动画；颜色过渡留待卡片内页面拖动切换落地后统一设计）。
      召唤即随机语义不变：召唤 = 全标签色列重随 + accent 取选中项
    - **标签块**（paint_tab_chip，§六 共享组件）：**无边框色块**——
      上两角圆角 R=1 格、**下缘直边**；竖向分色：
      **选中 = c1（顶）→c2（底）竖向均匀渐变满填 α255**（十二修推翻
      十一修「上 2/3+下 1/3 两截±3px 短渐变」——实机判「硬切换」，
      均匀渐变才是约定形态）+ 文字换深色反差（CARD_PAGE_BG）；
      **未选中 = c1（顶）→c2（底）竖向均匀渐变薄态 α48 满块**
      （十三修推翻「上/下 1/3 条带+中 1/3 留 6% 白底」三段硬切——
      实机判「暗块依然硬切」，t = dy·255/(h−1) 与选中同一把尺，
      只降 alpha 不降连续性）+ 文字 0.5 白
    - **底线组件·两模式**（十一修新立）：标签行下缘紧挨 1px 细线，
      宽 = 二级框（池区）同宽，空态也画。模式①**自身反转渐变**
      （c2→c1 页环同尺采样，§三 嵌套反转——留档他用）；模式②
      **配合标签** = 整根选中标签 c2 纯色 α255（配置页采用——
      选中块下 1/3 与底线同色一体）
    - 移动动画：fx_spring 弹簧沿用（选中块滑向新标签；文字不随弹簧，
      各就各位）
    - **退役**：开口框/线长随机机制——cursor.rs 几何与
      paint_open_cursor 涂装封存待文件树光标复用（kfmv4 开口框仍是
      文件树光标的指定形态，三~五修标定值保留在 §七 登记表）
    - 左缘对齐不变：标签行原点 x = 61 = 双池左框左缘（环粗左缘
      16+9 + 2 格内边距）
  - **手势仲裁**：标签行上的横向滑动不触发面板拖拽/页面滑向
    （与 kfmv4 `touch-action: pan-x` 隔离同义）
- **二层双框**：首行布局区之下是内容双框，两池间留 1 格间距
  （2026-09-12 实测修订：直接衔接太密），与首行留标准间距

## 五、双池（上池/下池）——kfmv4 系列的灵魂

两个二级卡片，上池下池**动态高度**（数学钉，A1 拍板）：

- 可用高 H = 卡片内容区高 − 首行布局区
- **上池高 = min(上池内容高, H/2)**：内容几行就跟几行；内容多时
  不超过下池，超出部分上池内滚动
- **下池高 = H − 上池高**：恒撑满剩余——下池内容少也撑到卡底
- 两池内容都多 = 各半，上池滚动
- **上池空也占位**（A2 拍板）：无内容时上池框保留占位不消失——
  池页切换时双池高度生长动画需要它；占位高 4 格（二标 2026-09-12：2 格太矮）

### 双池的目录语义（2026-09-13 用户拍板，三层目录宪法；同日二版修订）

双池不是两个通用容器，是**目录导航的三级映射**，语义钉死：

1. **根目录（大类）= 卡片顶标签栏**：池卡的各大类（系统管理/未来的
   API/角色/工具…）在首行标签栏，点击切换（§四 条款不变）
2. **子目录选择 = 下池**：当前大类的子目录列表放在**下池**，
   聚焦行 = 选中子目录（聚焦态样式走 §五 池行条款）
3. **二级选项 = 上池**：聚焦子目录里的具体选项放在**上池**；
   下池聚焦移动 → 上池内容整体切换
4. **上池下拉框 = 内容自身的选项切换器**（二版修订，推翻初版
   「与下池双向联动」）：上池顶部的下拉框服务的是**上池内容
   内部**的选项集（如服务器配置卡的「默认服务器」下拉 = 服务器
   池），**不与下池联动**——下池只管子目录，选项集只管内容。
   样式与行为对齐 kfmv4 池卡实证（API 卡 Provider 下拉模式）：
   下拉 = 字段框值位 + 右缘 ▼，换选 = 下方内容联动刷新
5. **三级框 = 上池内容行本身**（二版修订，kfmv4 实证 4 图拍板）：
   上池的每个选项/字段 = 一个圆角深色框行（标签列 + 值框），
   不是裸文字行；需要更深层展开时仍走全屏页（初版条款 5 不变）
6. **三级展开 = 全屏页**：二级选项需要再展开（三级目录）时，
   点击该选项弹出一个**全屏页面**——不进双池，不挤压双池布局
7. **组件池页**（2026-09-13 九修新立，用户拍板）：配置卡第二标签
   「组件池」——组件库的实机花名册，**唯一信息源 =
   `src/ui/comp_registry.rs` 常量表**（页面直接读表渲染，禁止
   手抄第二份清单）。目录映射不变：大类（组件分类）= 下池行
   （meta = 类内组件计数）；小类（组件条目）= 上池行
   （label = 组件名，value = 状态：现役/封存/计划）；**点上池行 =
   开跳框看详情**（§六 跳框条款），不开全屏页——详情是只读档案，
   不是三级目录。组件池页无下拉框（选项集是系统管理页的内容家具）

### 池行（二版：对齐 kfmv4 池卡实证样式；三版：圆角/间隔拍板；
### 四版 2026-09-13：左粗线/大字大行距/上池滚动，kfmv4 实证 4 图量化拍板）

- 行体 = **圆角深色框**（三级框工艺）：填充 = **渐变暗底**（十二修，
  §三 渐变暗背景条款——取代四版起沿用的 4% 白平填）、
  **圆角 = 池框同尺 36px**（三版拍板：12px 小圆角是**标签光标专用
  样式**——未来文件树光标用，其他场合禁用；四版行高 ×2 后 36px
  落在 144px 行上比例 0.25，与 kfmv4 实证的偏方正观感同源）
- **左粗三边细（四版立、六修收窄、七修角部渐细、十一修渐变色归位、
  十二修未选中去框）**：三级框**整框进 135° 双色渐变体系**（十一修，
  用户拍板：「三级框应该遵守渐变色反转的规律」）——与页环**同向**
  c1→c2（§三 逐层反转：页环正 → 池框反 → 三级框还原）。
  **角部渐细只渐形状不渐色**（十一修推翻七修混白）：左粗缘在角部
  弧线上厚度渐细入细边，颜色全程渐变采样。非对称内芯配方不变
  （内芯左让 10/其余让 3、半径 R−3，角心偏移 = 渐细来源）。
  **选中/未选中形态（十二修重订，用户拍板：「暗形态把所有框都取消，
  只留渐变暗背景」）**：**选中 = 全包框**（左粗竖线 10px + 三细边
  3px 整环 α255 渐变 + 渐变暗底）——可选列表行（下池行/下拉选项行）；
  **未选中 = 无框**（框墨全退，只剩圆角渐变暗底——细边薄态 α140
  与角弧 alpha 过渡随十一修薄态一并退役）。
  **上池值框无边框化**（十二修，用户拍板：「无边框了左侧那坨竖线
  很丑」）：十一修形态②「只有左竖线」退役——值框 = §六 无边框
  组件，圆角渐变暗底 + 值文本，无任何框墨（与非池行场合的均匀细框
  paint_thin_frame 分家不变）
- **行高/字号四版标定，六修值框收紧，七修行隙分池**（用户拍板：
  值框上下线各往中心缩半格）：字段框**行** 4 格 = 144px 不变，

  6% 白底」废弃不变
- **上池滚动（四版兑现 §五「超出部分上池内滚动」——v1a 欠账，

  锁定才让路页面跟手，纵向滚动期间横向锁未起（§四 手势仲裁同规）

  **删除前必弹确认框**；✕ 点击不触发行选中（v1b 才启用）
- **池区动画两件（十五修新立，2026-09-14 用户拍板；BAR-094 弹簧废除
  改缓动；BAR-095 二十一并入分域律，2026-09-15 用户拍板**「不要
  过冲，不是把动画搞没——用跟光标一样速度的动画，光标到位池高
  也到位」**）**：
  1. **上池池高缓动（分域律）**：上池内容高变化 →
     - **Upper 域（点下池行）**：池高 **250ms ease-in-out cubic 缓动**
       与光标滑行/上池内容平移**同钟同曲线**（select 同刻挂账）——
       「光标移动到位，池高变化也到位」，三量严格同步零过冲；
     - **Page 域（切标签）与非平移变更**：池高 = 目标值起步帧就位
       （「新页面就是新页面」——新页用自己的行高平移进来，贴死后
       无任何二次动画；PanMove 新代烘的就是终态池高，贴死零跳变）。
     - 欠阻尼弹簧（ζ=0.76 过冲「墩一下」）从未被用户要求，BAR-094
       废除不复辟；缓动重定基续滑（狂点不跳变）。下池随 §五 布局
       数学自动互补（它是差的函数，零专门动画）。
  2. **下池光标滑行（缓动核）**：点选其他大类 → 选中光标框（全包框）
     按 **250ms ease-in-out cubic 定时缓动**滑向新行（PAN_MS 同钟同
     曲线——select 同刻挂平移账，光标滑行与上池内容平移严格同步；
     全程单调不过靶零过冲，欠阻尼弹簧判「瞬移+过冲」废除）。上池
     内容与页色**即时切换**不等光标（光标是视觉向导不是闸门——与
     标签栏游标同规）。切标签页时光标直接落首行不滑行；行表 clamp
     改 focus 不动画。
  - 命中口径：光标滑行/池高缓动期间命中吃**逐帧同一份动画几何**
    （眼手同尺不破）；帧泵 = 动画活跃按需置脏（与动效展品帧泵
    同闸，无动画零帧纪律不破）
- **动画曲线单一源（BAR-095 新立纪律，2026-09-15 用户质询
  「你是不是没引用全局单一源」定案）**：
  1. **位移类动画**（平移/滑行/伸缩）一律 `fx_ease::ease_in_out_cubic`
     250ms——配置页池平移/下池光标/池高缓动/标签栏游标同一把尺；
  2. **减速类**（跟手后的松手补间）用 power2_out 族（面板召唤/收起，
     2026-09-11 用户拍板两臂减速）；
  3. **fx_spring 欠阻尼弹簧只许两处**：键盘 inset（D5 拍板）+组件池
     弹簧展品的自展示——新代码引弹簧即违宪；
  4. 新动画入册三同步：ui-base §二注册表 + 组件池（comp_registry）
     条目 + 预览动画曲线，**三处任一与实现漂移 = 红**（组件池是用户
     核对实现的口径）；展品预览动画的曲线必须与它所演示的实机动画
     同款，不得自编。
  5. 已知债（BAR-096 挂账）：光标/游标/池高的 sig 维逐帧触发配置槽
     全页重烘（~47ms/帧，draw_avg 实测）= 250ms 动画只画 5-7 帧
     =「跳变感」真凶——根治 = 光标框/游标/池框合成期化拆槽
     （ui-base §八债单）

## 六、控件与组件

- **组件**（2026-09-13 六修新立，用户拍板）：**无边框**的文字容器，
  可编辑或仅展示。组件靠位置与字档表达归属，不借框——字段框行的
  标签列、未来的文本编辑位都是组件。组件与装修框是并列的两类
  视觉元素：框装内容受 §三 最小容量律约束，组件无框不受（但它的
  宿主行/宿主框受）
- **按钮**：全宽均分（flex:1 语义），禁止短按钮；按钮必须在框内部，
  不悬在框之间
- **提示文本**：禁 emoji，用 `[错误: ...]` / `[已取消]` 式纯文本
- **确认框**：双色渐变边框（c1→c2）+ 深底，网格像素风同 §一；
  Enter 确认 / Escape 取消
- **下拉栏**（2026-09-14 十三修重订，用户拍板）：自绘组件——
  **触发器 = 三级框**（全包框：左粗竖线 10px+三细边 3px 整环渐变
  α255，与可选列表行同形态——它是选择控件）+ 右缘 ▼；
  **展开面板 = 整面圆角无边框深底**（圆角 = 池框同尺 36px 按短边
  一半钳，近黑 α252——十三修加深，旧 96%/α245 退役），无单体外框；
  **面板内选项行 = 方形**（无圆角、无个体背景，文字直接坐深底），
  **选中行 = 均匀细框**（paint_thin_frame：四边 3px 渐变 + 渐变
  暗底芯）；底部栏向上弹、顶部栏向下弹（kfmv4 教训：方向反了
  会弹出屏外）；
  **面板宽（十七修 BAR-090，2026-09-14 用户拍板**：「这确实是一个
  问题」）**：= max(触发器宽, 选项最长文宽+双侧内边距 54px)，
  **右缘与触发器右缘对齐、加宽向左长**（钉考题实锤修宪：触发器
  右缘 ≡ 池内容内缘——值框锚行右缘恒等式，初稿「左对齐+右钳」
  几何锁死宽度）；左缘钳池内容左内缘——选项是面板的内容主体，
  宽必须装得下内容（触发器文比选项短时裁选项末字的实锤见
  bugs.md BAR-090）；
  **开合动画两件（十五修新立，用户拍板**：「扩出来的面板需要平滑
  动画」「标签移动的同时面板收起」）：
  ①**展开生长**——面板从触发器下缘起 0→全高 250ms ease-out
  （fx_ease 同族臂）；
  ②**选中收起 = 两段时序（2026-09-14 用户拍板修订**：「有一个明显
  的里面的选中框移动的动画，这个动画播放完毕后，再触发下拉栏
  回收的动画」）——点选**其他**行 = Ⅰ段：选中细框从旧行
  **滑动**到新行（160ms ease-out，滑动中面板冻结保持当前展开度、
  触发器值即换），Ⅱ段：滑到后面板才从冻结进度 180ms ease-in
  收起；点选**当前**行 = 无 Ⅰ段直接收；外点收起 = 直接 180ms
  ease-in（无 Ⅰ段）。
  ③**抽屉随面（十七修新立，用户拍板**：「内容跟随背景走，像抽屉
  里的东西一样」）——选项行+选中细框与面板背景是**同一刚体**：
  涂装 y 偏移 = −(全高−当前高)，随面板当前高裁剪。展开 = 刚体从
  触发器后滑出（下方选项先入场），收起 = 整体滑回触发器后（上方
  选项先没入触发器）；内容钉顶只裁底的帘幕式（初版「选项行随
  面板当前高裁剪」）退役——「面与内容一体」通则的垂直向实例。
  ④**▼ 旋转（十七修新立，用户拍板）**：触发器右缘三角不再是文本
  字符——**矢量三角**（17×9 同尺）绕中心旋转，角 =
  dropdown_progress×180°：展开 0°(▼)→180°(▲)，收起回 0°，
  两段时序Ⅰ段冻结在 180°（面板冻结三角同冻）。
  展开/收起进行中**选项不命中**（防眼手错位），点按 = 收（展开
  中触发挥收、收起中即时归零）；收起中面板余影不穿透触摸
- **「面与内容一体」通则（视口平移切页，2026-09-14 十七修新立，
  用户拍板**：「这个模式需要能复用……值得写进宪法」）：承载面与
  它的内容是**一个刚体**——动画移动的是**视口**，不是元素替换。
  三个实例：
  ①**标签切换 = 页面级视口平移**：视口 = 页面最外层框（页环），
  标签栏/页环不动，**双池框+池内容**整体平移（旧代连框带内容出、
  新代进）；
  ②**下池选行 = 上池级视口平移**：视口 = 上池框，**上池内容**
  整体平移，下池与双池框不动——**上池框本身也不动**（十八修
  修宪，BAR-091）：平移裁剪带 = 上池**内容矩形**（池内缘内缩
  POOL_CONTENT_INSET），池框/左粗竖条一像素不进带——旧版带
  左缘 x+4 吞了粗条右半（条宽 9px），框随内容滑 = 视觉断裂；
  ③**下拉 = 垂直抽屉**（见下拉栏条款③）。
  **方向律**：选择增量为正（标签右移/下池光标下移）→ 内容左移
  （旧左出、新右进）；增量为负 → 右移。**横竖控件同律**。
  **双代同画**：过渡帧里旧代与新代各画一份带偏移**同帧**在屏，
  禁「先出后进」两拍——「视口在整块内容上移动」的读感正来自
  同帧。**留隙律**（2026-09-15 十八修新立，用户实机录屏拍板：
  「不要直接紧贴，这是挤；视口平移需要页面外有一个隐藏的布局
  状态」）：双代在内容轴上**恒定留隙 G**——旧代右缘与新一代
  左缘间距全程 = G，平移距 = 视口宽 + G。G = 2× 静态时内容
  缘距视口缘的距离：页面级 G = 2 格（池卡外缘距页内容带缘
  1 格的两倍）；上池级 G = 4 格（内容距池框缘
  POOL_CONTENT_INSET 2 格的两倍）。**时长** 250ms
  **ease-in-out cubic**（十八修改：ease-out 起步即满速读感
  「太块」；ease-in-out 起步收步皆柔 = 视口滑动行业标准形）；
  平移期整页换色/光标缓动即时并行，池高 = 起步帧硬切随新代
  （BAR-094：弹簧废除，无「并行不辍」的池高动画了）。旧代 =
  冻结快照（行表/上池/选项/滚动/双池几何/页色），新代 = 活态涂装
- **组合键录入控件**（2026-09-13 用户拍板）：修饰键（Ctrl/Alt 等）
  走**下拉选择**，无修饰键显示一条短线「—」；键名**手动填写**
  （终端两行快捷键行有功能键，用户自己能打出来）——**不做按键
  捕获式映射绑定**
- **跳框（modal，2026-09-13 九修新立，用户拍板；kfmv4 跳框三截图
  实证）**：模态详情卡——盖着内容出现的覆盖层（§一 覆盖层特许
  同源），规格：
  - **压暗层**：本页面区域整层混黑 α150，吃下层全部触摸（模态 =
    下层手势全家让路）
  - **居中卡片**：paint_rect_ring 同配方（池框同尺 R=36px 圆角、
    内卡反转色向 c2→c1、深底 CARD_PAGE_BG），距屏左右各 3 格，
    垂直居中，高随内容（封顶可视区，v1 超出截断不做滚动）
  - **标题**：组件名 36px faux-bold 0.85 亮，居中，占 2 格
  - **分隔线**：标题下 1px 渐变细线，卡内宽，色向 = 内卡反转
    c2→c1（与标签行底线同规——二级组件）
  - **字段区**：每条字段 = 题注（30px、0.5 灰）**在上** + 内容
    （36px、0.85 亮，折行随卡宽）**在下**——**与上池字段行的
    字档相反是有意的**（九修拍板）：上池行里标签是行的标题，
    跳框里题注是内容的脚注（名/状态/位置/规范/考题/说明）
  - **预览画板**（2026-09-13 十修新立，用户拍板：「重点是这个内容，
    而不是档案——让我看到组件具体是什么样子」）：分隔线下、字段区
    上一个**实时渲染展台**——均匀细框工艺（paint_thin_frame，十一修
    换；内芯渐变暗底，十二修）、卡内宽、6 格高，上下各留 0.5 格呼吸；画板内容
    = **该组件的实涂装微缩实时渲染**（渲染种类 = comp_registry 条目
    的 preview 维，涂装归 termview 预览段——原语全复用共享件：
    paint_rect_ring/paint_row_frame/paint_tab_chip/paint_open_cursor/
    orb sprite/gear paint_at；动效引擎类画函数曲线/示意图）。画板是
    内容不是档案——与字段区的关系 = 展品与题签。
    **动效引擎四件（弹簧/缓动/手势仲裁/视口平移）预览 = 动画演示**
    （十四修新立，用户拍板：「用一个小白圆球作为手指触摸，让示例
    动起来」）：静态示意图为底，上叠动画层——**白球（r10、α220）

    松手段走弹簧/缓动曲线），循环 2400ms；帧驱动 = 涂装入参
    now_ms（单源可测），帧泵 ≤30fps 按需启停（无动画零帧同 §四）
  - **关闭钮**：卡底全宽、3 格高、**均匀细框**（paint_thin_frame，
    十一修换；内芯渐变暗底，十二修）+ 居中 36px 亮字「关闭」
  - **交互**：点框外或「关闭」= 收起；框内其他位置点按 = 无操作

## 八、与底本的偏差登记（诚实清单）

- kfmv4 卡片堆模式废弃：NA 配置单卡 + 页内标签栏切池（用户拍板②）
- 随机锚点从「召唤卡片堆」改为「每次召唤该页面」（C2 拍板）
- 圆角/连续渐变/毛玻璃**不一刀切放弃**（2026-09-12 二修，用户纠偏）：
  改三层视觉语言——布局咬格/描边精度自由/内容网格原生/覆盖层特许
  半透明虚化；设计哲学命名 Hi-bit（高精度低像素）
- 标题栏废弃：无标题栏概念，首行自开布局区（A3.1）
- 标签选中态 = 光标框（底本无此条，新立；2026-09-12 三修：形态/颜色/
  底色复刻 kfmv4 canvas-cursor 开口框，线长改随机机制，呼吸/液体光
  不移植；四修：线宽/圆角改 NA 装修框同尺标定（细 3/粗 9/R12），
  左线收进框内缘与双池左框对齐，kfmv4 的 1.65px 突出不移植——
  见 §四）
- 双池高度数学钉（底本只有「两框直接衔接」，高度规则是新立条款）

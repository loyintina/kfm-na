# KFM-NA 主题宪法（theme.md）

> **地位：KFM 主题的唯一来源。** 任何 UI 视觉决策以本文为准；本文没写的，
> 先修宪再实现，不许自由发挥。
> 底本：kfmv4 `docs/guides/card-dev.md` §10 视觉规范 + §11 组件 +
> `docs/domains/floating-card/contract.md`（久经验证的条款原样保留）；
> 2026-09-12 用户修宪拍板（C1-C3/A1-A6 全裁）翻成 NA 网格像素语境。
> 与 kfmv4 底本冲突处以本文为准（底本是 web/DOM 语境，本文是 Rust 网格语境）。

## 一、总则：网格×像素中间态

**网格布局是我们的灵魂，不能丢。** 终端是粗糙的网格字符、UI 是精致的
圆角细节——这两者在 kfmv4 和 na 里长期割裂，NA 走中间态：
像素 UI 与终端网格结合。2026-09-12 二修：设计哲学正式命名 **Hi-bit**
（高精度低像素——业界通称；Square Enix「HD-2D」、Minecraft HD/PBR
材质包是同思潮变体）：**低分辨率的骨架，高分辨率的血肉**——宏观
结构量化到格，微观渲染允许无限精致（渐变/光晕/法线/光照，未来
glyph 贴图带法线做逐格光照是字面意义的 hi-bit 终端）。

**三层视觉语言**（割裂的防线在布局层，不是锁死渲染层——反例：
光球平滑光晕飘在网格终端上从不割裂，无体系混用才割裂）：

- **布局层（咬格，不让步）**：卡片内所有元素（边框盒、行、间距、
  光标框）的位置和尺寸以终端格子（CELL_W/CELL_H）为单位，
  禁止半格漂移
- **描边层（精度自由）**：边框/光效/圆角怎么画是渲染层的事，
  不破坏布局对齐即可。默认形态：渐变用**逐格色阶**（边框每格沿
  135deg 在 c1→c2 间取色——一屏四五十列=四五十步色阶，肉眼近
  连续，便宜且是品牌语言）；圆角默认**像素切角**（角部沿格对角
  切掉，方块世界原生公民），平滑圆角描边留作特例；光晕类效果
  （光球先例）允许连续渐变
- **内容层（网格原生）**：文字/列表行按格排布，行=2 格、
  标签行=2 格（2026-09-12 真机实测修订：1 格太扁），字号走格子
  变量——双指缩放改格子尺寸，全部 UI 自动同源缩放（A5 拍板）。
  **半格特许**（2026-09-13 四修）：池卡行高允许半格标定（如 4.5 格，
  字号倍数驱动的实测拍板值）；元素**原点仍咬格**，半格只许出现在
  高度/留隙维度
- **覆盖层特许**：浮层/对话框/下拉面板这类「盖着内容出现」的层，
  允许半透明+背景虚化（毛玻璃解决的是层间可读性，不是形状语言；
  AI 浮层盖终端是标准用例）。全屏页面不透明，用不上

## 二、色彩体系

### 2.1 项目主题色（不可改，宪法级）

- 终端卡灰白、AI 对话页蓝紫、光球紫——项目主题的重要来源，永不随机

### 2.2 随机 accent（召唤即随机）

- **纳管范围**：文件树页、解析页、配置（设置）页——三个可召唤页面
  **每次召唤重新随机**；AI 页不纳入卡片体系（A6/C2 拍板）
- **生成算法**（kfmv4 `card-stack.ts _generateRandomAccents` 原样移植，
  约束区间 HSL 随机，不策展不抽板）：
  - c1 色相 = 随机 0–360°
  - c2 色相 = c1 ± 30°–120°（避开同色与正对的撞色）
  - 饱和度 = 45%–70%（双色共享）；亮度 = 50%–65%（双色共享）
- **反向重开沿用**：关闭中途再拉开（closing→opening 反向分支）必须
  沿用本次已生成的配色，禁止可见跳色（kfmv4 BAR-CARD-ACCENT-01）
- **背景固定深底**：卡片底色不随 accent——深底近黑
  （kfmv4: `rgba(20,16,32,0.92)`），颜色信息全由边框/装饰承载

### 2.3 文字

- accent 色**永不用于文字**（随机色可能落亮色区间与底色冲突）
- 白色三档：标题 `rgba(255,255,255,0.85)` / 正文 0.75 / 次级 0.5

## 三、边框体系

**框分两类（2026-09-12 三修，用户拍板；2026-09-13 五修，功能光标
颜色条款推翻重订）——装修框与功能光标，形态纪律不同源：**

- **装修框**（页环/池框/卡片框——页面的装饰骨架）：吃随机 accent
  （§2.2），规则如下各条
- **功能光标**（选中态指示框——标签栏光标、未来的文件树滚动光标）：
  **颜色跟随本卡随机 accent 双色渐变**（2026-09-13 用户拍板，推翻
  09-12「固定纯蓝永不随机」决策）——与页环同一把 135° 渐变尺同源
  采样（同一渐变框原点/分母，光标像从页环的渐变布上剪下来的），
  随召唤换装；α 仍 0.7。底色固定 `rgba(46,213,163,0.15)` 绿青
  半透明垫层（kfmv4 canvas-cursor 原样复刻）。形态为**开口框**
  （只有左边+顶线+底线，无右边），规格见 §四 标签栏条款

装修框规则：

- **左粗三边**：左边粗、其余三边细；粗细比 = 3:1（kfmv4: 左 3px 其余
  1px，NA 按格标定——A4 拍板宪法只钉相对比例）
- **135deg 双色渐变**：c1（起点）→c2（终点），默认逐格色阶实现（§一）
- **角部形态**：默认像素切角（沿格对角切角）；平滑圆角描边为特例，
  需登记用途（§一 描边层）
- **多级嵌套逐层反转**：外壳 c1→c2 → 内卡 c2→c1（反转）→ 子卡 c1→c2
  （还原）→ 孙卡再反转。**透明度不降**——内外卡同饱和度同视觉重量
- **层级归属原则**：卡片内没有裸元素，每个可见元素归属某一层框；
  同层元素统一边框样式、统一间距

## 四、卡片骨架

- **无标题栏概念**：整张卡都是内容区；需要标题/标签等结构时，
  在首行自开布局区域实现（A3.1 拍板）
- **标签栏**（配置卡首行布局区，A3 拍板）：
  - 横滑区（内容超出可横滚）；标签点击切换池页，池类可追加
  - **选中态 = 功能光标开口框**（2026-09-12 三修，用户拍板复刻
    kfmv4 canvas-cursor；初版左粗渐变封闭环 R16 在一堆装修框里
    不协调，废弃。同日四修：kfmv4 像素直搬太细与全页不匹配——
    线宽/圆角按 NA 装修框同尺标定，左缘与双池对齐）：
    - 几何：左强调线 8px 画在**框内缘**（2026-09-13 五修实机标定：
      9px 用户判粗 1px，改为 8px——不再钉死粗左缘 3×W 同尺，光标
      左线宽度以实机观感为准；
      kfmv4 的 1.65px 突出取消——装修框左缘都在框内，光标同规）；
      左上/左下圆角 R=12（kfmv4 R:细线 = 4:1 比例 ×3 缩放），
      线宽沿弧渐变（角顶 8px→角尾 3px），**弧带外缘贴框缘向内铺**
      （dist=R 满覆盖、dist>R 零墨，与直线段框内缘贴边同源同尺
      不跨框——BAR-087：居中弧带对半跨边会让三条线在角上错位）；
      顶线 3px 锚左，
      底线 3px 锚左；**无右边**
    - **左缘对齐**：标签行原点 x = 61 = 双池左框左缘（环粗左缘
      16+9 + 2 格内边距）——光标左粗线与上下双池左框逐像素一线
    - **线长随机机制**（NA 特有，用户拍板）：kfmv4 顶线长=文字宽、
      底线长=剩余——标签不像文件行够宽且字数随机，跟随文字会让
      上下线近似对齐；改为**每次选中切换重掷**：顶/底线长各自
      随机 ∈ [20px, 框宽−10px−R]，且保证 |顶−底| ≥ min(1 格, 域幅/2)
      （上下不对齐是观感本体，构造保证恒真）。**四修增补**：上限
      多减一个 R——线从圆角弧尾（x0+R）起画，kfmv4 靠 R=4<10 隐含
      不越界，R=12 后必须显式收域，线尾距开口右缘恒 ≥10px
    - 颜色：跟随本卡随机 accent 双色渐变（§三 功能光标条款，
      2026-09-13 五修：与页环同一把 135° 渐变尺同源采样）α0.7；
      底色 `rgba(46,213,163,0.15)` 垫整个框体（标签本身无框，
      只有光标落脚处出现底+三线）
    - 移动动画：暂沿用 fx_spring 弹簧（600ms 贴死）；kfmv4 是
      GSAP power3.out 0.18s——差异待第二个标签落地做移动动画时
      实机对比再审（用户拍板缓议）
    - 呼吸/液体光**不移植**：kfmv4 那两个动效是模式联动特殊选中
      态专属，NA 无此场景（用户拍板）
  - **手势仲裁**：标签行上的横向滑动不触发面板拖拽/页面滑向
    （与 kfmv4 `touch-action: pan-x` 隔离同义）
- **二层双框**：首行布局区之下是内容双框，两池间留 1 格间距
  （2026-09-12 实测修订：直接衔接太密），与首行留标准间距

## 五、双池（上池/下池）——kfmv4 系列的灵魂

两个二级卡片，上池下池**动态高度**（数学钉，A1 拍板）：

- 可用高 H = 卡片内容区高 − 首行布局区
- **上池高 = min(上池内容高, H/2)**：内容几行就跟几行；内容多时
  不超过下池，超出部分上池内滚动
- **下池高 = H − 上池高**：恒撑满剩余——下池内容少也撑到卡底
- 两池内容都多 = 各半，上池滚动
- **上池空也占位**（A2 拍板）：无内容时上池框保留占位不消失——
  池页切换时双池高度生长动画需要它；占位高 4 格（二标 2026-09-12：2 格太矮）

### 双池的目录语义（2026-09-13 用户拍板，三层目录宪法；同日二版修订）

双池不是两个通用容器，是**目录导航的三级映射**，语义钉死：

1. **根目录（大类）= 卡片顶标签栏**：池卡的各大类（系统管理/未来的
   API/角色/工具…）在首行标签栏，点击切换（§四 条款不变）
2. **子目录选择 = 下池**：当前大类的子目录列表放在**下池**，
   聚焦行 = 选中子目录（聚焦态样式走 §五 池行条款）
3. **二级选项 = 上池**：聚焦子目录里的具体选项放在**上池**；
   下池聚焦移动 → 上池内容整体切换
4. **上池下拉框 = 内容自身的选项切换器**（二版修订，推翻初版
   「与下池双向联动」）：上池顶部的下拉框服务的是**上池内容
   内部**的选项集（如服务器配置卡的「默认服务器」下拉 = 服务器
   池），**不与下池联动**——下池只管子目录，选项集只管内容。
   样式与行为对齐 kfmv4 池卡实证（API 卡 Provider 下拉模式）：
   下拉 = 字段框值位 + 右缘 ▼，换选 = 下方内容联动刷新
5. **三级框 = 上池内容行本身**（二版修订，kfmv4 实证 4 图拍板）：
   上池的每个选项/字段 = 一个圆角深色框行（标签列 + 值框），
   不是裸文字行；需要更深层展开时仍走全屏页（初版条款 5 不变）
6. **三级展开 = 全屏页**：二级选项需要再展开（三级目录）时，
   点击该选项弹出一个**全屏页面**——不进双池，不挤压双池布局

### 池行（二版：对齐 kfmv4 池卡实证样式；三版：圆角/间隔拍板；
### 四版 2026-09-13：左粗线/大字大行距/上池滚动，kfmv4 实证 4 图量化拍板）

- 行体 = **圆角深色框**（三级框工艺）：填充 4% 白、
  **圆角 = 池框同尺 36px**（三版拍板：12px 小圆角是**标签光标专用
  样式**——未来文件树光标用，其他场合禁用；四版行高 ×2 后 36px
  落在 144px 行上比例 0.25，与 kfmv4 实证的偏方正观感同源）
- **左粗三边细（四版通用化，推翻三版「四边均匀细描边」）**：
  左缘 = 粗渐变条（accent 双色、页环同尺 135° 采样、竖胶囊端、
  宽 10px、竖跨 R/2 收边——kfmv4 实证选中行左边 ≈11px @1260 宽，
  左粗：细 ≈ 3:1 合 §三 装修框比例），其余三边细描边
  （未选中 8% 白，选中 = accent 渐变 3px）。**所有三级框恒有左粗条**——
  kfmv4 只给选中行是 DOM  hover 语境，NA 触屏无 hover，框的可读性
  靠恒在的左粗条承载（用户拍板：「框的左竖线加粗」）
- **行高/字号四版标定**（用户拍板：字体行高 ×1.5、三级框 ×2；
  kfmv4 实证量化基线 @1260 宽——字段框 65px/字 ~28px、下池行
  ~122px/标题 ~30px 副 ~22px、行隙 ~20px、池内边距 ~40px）：
  字段框行 **4 格 = 144px**（2 格 ×2）、下池行 **4.5 格 = 162px**
  （3 格 ×1.5，半格特许 §一）、行隙 **1.5 格 = 27px**、
  池内容内边距 **2 格 = 36px**（1 格实机太窄）、
  标签列 **12 格 = 216px**（字号 1.5 倍后 8 格截断 5 字标签复发防）
- 双行结构：标题行（faux-bold、0.85 白、**36px = CELL_H**）+
  元信息行（0.5 白、**30px = CELL_H×5/6**），标题带 90px（×1.5）
- 选中态 = accent 双色渐变细描边（三边，上条）——初版「聚焦 =
  6% 白底」废弃不变
- **上池滚动（四版兑现 §五「超出部分上池内滚动」——v1a 欠账，
  行高 ×2 后 10 字段行恒溢出，被迫落地）**：像素级 1:1 跟手
  （手指上推 = 内容上移），clamp [0, 内容高−池高]；滚出池缘的
  行/文字按池内缘裁剪带裁掉；横向手势不冲突——panel_drag 横向
  锁定才让路页面跟手，纵向滚动期间横向锁未起（§四 手势仲裁同规）
- 删除：右侧红色 ✕（`rgba(255,100,100,0.6)`，hover 变亮），
  **删除前必弹确认框**；✕ 点击不触发行选中（v1b 才启用）

## 六、控件与组件

- **按钮**：全宽均分（flex:1 语义），禁止短按钮；按钮必须在框内部，
  不悬在框之间
- **提示文本**：禁 emoji，用 `[错误: ...]` / `[已取消]` 式纯文本
- **确认框**：双色渐变边框（c1→c2）+ 深底，网格像素风同 §一；
  Enter 确认 / Escape 取消
- **下拉栏**：自绘组件——触发器 6% 白底；面板深底（近黑 96%）+
  选中项 ✓ 标记；底部栏向上弹、顶部栏向下弹（kfmv4 教训：方向反了
  会弹出屏外）
- **组合键录入控件**（2026-09-13 用户拍板）：修饰键（Ctrl/Alt 等）
  走**下拉选择**，无修饰键显示一条短线「—」；键名**手动填写**
  （终端两行快捷键行有功能键，用户自己能打出来）——**不做按键
  捕获式映射绑定**
- **样式唯一来源**：所有卡片样式走 Rust 组件层公共 helper，
  **禁止逐卡手抄**（kfmv4 教训：6 张卡手抄 20+ 次遍数不同，
  无模板必漂移）

## 七、数值体系（A4 拍板）

  池行 = 4.5 格、字段框行 = 4 格（四版：×1.5/×2 拍板）、标签行 = 2 格

  sat 45–70%、lit 50–65%

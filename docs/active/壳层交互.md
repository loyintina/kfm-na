# 壳层交互（2026-08-21，三件套一次落地）

> 背景：用户两次抱怨「字太小」；欠账清单里挂着双指缩放。本页是三个壳层
> 交互特性的行为规格——状态机定义与坐标换算约定都在这，是交接面。
> 实现：src/termview.rs（选择/几何面）+ src/android_app.rs（触摸路由）+
> src/clipboard.rs（JNI 薄壳）。考题：tests/select_spec.rs +
> tests/termview_spec.rs 缩放三节。

## 1. 默认字体放大

- 基准格尺寸 `CELL_W/CELL_H` 15×30 → **18×36**（1080×2400 屏净宽 1056px
  ≈ 58 列）。基准同时是捏合缩放的 ratio=1.0 锚点与无持久化时的冷启动默认。
- 顶带动态化：`MARGIN_TOP` 常量保留（= 基准格高下的值，旧考题继续钉），
  渲染/布局一律走 `margin_top(cell_h) = MARGIN_Y + cell_h`——BAR-010 的
  「圆角屏下探一整行」语义在任一档缩放下不变。

## 2. 双指捏合缩放

- 手势判定：touch.id 跟踪终端区指头（keybar 带上的不登记）；**两个指头
  都在终端区**（`keybar::in_bar` 判定之外）即进捏合态。捏合期间滚动/
  点按/长按全部让路（touch_scroll/press 清零），任一指抬起结束，
  残余指头不接管任何手势（防滚跳/误弹键盘）。
- 缩放数学：`cell = pinch_cell_size(起手格尺寸, dist/dist0)`，钳
  cell_w∈[10,45]、cell_h∈[20,90]；非法比例（NaN/0/负/∞）落基准。
  整数结果与当前格尺寸不同才应用（防抖），应用 = `set_cell_size`
  （重算 font_px/baseline_off/CJK 三件套）+ `apply_window_size`
  （alacritty resize 自带 reflow，列行数随格尺寸反推）。
- 持久化：捏合收尾把缩放比浮点（相对基准 `cw / CELL_W`）写
  `files/kfm-zoom`（ndk `internal_data_path` 拼，不硬编码）；冷启动
  `init_terminal` 在首发 `apply_window_size` 前读回应用。写/读失败
  只上报不 panic。上报通道 `[zoom]`（捏合开始/持久化/冷启动读回各一行）。

## 3. 长按选择 + 复制

状态机（壳层半在 android_app，网格语义半在 termview）：

```
无按压 --Started(终端区)--> armed(press 记时刻/坐标)
armed --Moved 过 TAP_SLOP--> 滚动（原 TouchScroll 链路，armed 撤销）
armed --第二指落下--> 捏合（armed 撤销）
armed --RedrawRequested 查 ≥500ms 未动--> 选择模式（select_word_at 选落点词）
选择模式 --Moved--> 扩选（extend_selection，不滚屏）
选择模式 --抬手--> 保持高亮（刚触发长按那次抬手不复制）
选择模式 --按住边界格(hit_boundary 端点格 ±1 宽容)--> 边界精调
              （move_selection_end，端点跟手指、拖过另一端角色互换；
              放大镜浮窗随触点）
边界精调 --抬手/Cancelled--> 定型保持高亮，不复制
选择模式 --单击非边界区--> 复制 + Toast + 清高亮
```

- 词定义：`is_word_char` = 字母数字 + `_-./:~` 连续段（路径/URL/行号串
  整段拎出来）；落点非词字符只选该格（提取 trim 后为空则不打扰剪贴板）。
- 扩选：cursor 端跟手指，anchor 锚住；**反向拖过 anchor 时固定端翻转
  到词另一端**（整词保持在选区内）。跨行、跨历史区都支持。
- 边界直拖（2026-08-21 拖柄废除——水滴柄丑且白占一行高，改按住选区
  边界格直拖，不再画任何柄）：触点格与起/止端格的行差、列差都 ≤1
  即算抓住（触控宽容，hit_boundary）；两端同圈（相邻格小选区）取距
  触点像素近的一端，等距钉 Start。端点滚出可视区天然抓不到（触点
  总在屏内，距离必超圈）。
- 宽字符边界钳制（2026-08-21，端点永不劈 CJK 字）：拖动端点落在宽
  字符 spacer 半格时按拖动方向钳——右移钳 col+1（越过该字到下一格），
  左移钳 col-1（回到该字格 0）；select_word_at/extend_selection/
  move_selection_end 三入口同一把钳（方向 = 新落点 vs 被拖端旧位置
  字典序）。选词落点在 spacer 上当作按在格 0 再扩词，词尾宽字符把
  spacer 格带进选区。**固有结果（实拍判卷点）：右拖终点落 spacer 会
  把后一格也包进选区**（后一格非空白时多带一个字）。提取本就不收
  spacer（跳过），钳制前后提取等价——一致性考题用探针
  `set_selection_raw` 把端点人为放到 spacer 上钉死两条等价
  （start 在 spacer ≡ 钳右 col+1；end 在 spacer ≡ 钳左 col-1）。
  渲染层高亮整字扩边：spacer 的格 0 选中 → spacer 也亮，反之亦然。
- 放大镜：边界拖动中，触点正下方那格为中心，±5 格 × ±3 行帧缓冲源区
  最近邻 2 倍贴进 2px 边框圆角浮窗，底缘在触点上方 60px（不挡手），
  整窗钳在屏内。实现 = render_into 后从帧缓冲裁源区放大（先拷源区
  再贴，读写不自踩），不二次光栅化。
- 坐标约定（考题钉死，两边同一把尺）：
  - 渲染：屏行 = 网格行 + display_offset；格原点 = cell_origin +
    (MARGIN_X, margin_top(cell_h))。
  - 触摸：px_to_cell 减同一边距/顶带 floor 取格（越界钳网格边缘），
    网格行 = 屏行 - display_offset。选择以**网格坐标**（Line 含历史
    负行, Column）存储——滚屏后选区跟着内容走，高亮无需换算。
- 提取：归一化区间逐行收 `cell.c`；tab 本体还原（BAR-015 put_tab 写格
  的就是 '\t'）；宽字符占位格跳过、zerowidth 组合符带上；行尾空白
  trim，行间补 \n。
- 高亮：render_into 对选中格盖 `SELECT_BG`（kfmv4 正蓝 #3B82F6，
  2026-08-21 品牌色板统一；放大镜边框与拖柄同青色系 HANDLE_CYAN）。
  **两遍制渲染**（2026-08-21 实拍「选中态中文只剩左半」修复）：先全部
  背景（含高亮）后全部字形——单遍制时宽字符格 0 的双宽字形墨探进格 1，
  被 spacer 格的高亮填充盖掉右半。高亮随钳制整字扩边（见上条）。
- 单格字形格宽裁剪（2026-08-21 实拍 ⇄ 溢出修复）：模糊宽度字符
  （unicode-width 判 1 格，CJK 备用字体里是全角字形）右缘按 1 格宽
  clip；宽字符（WIDE_CHAR）路径保持 2 格宽。
- 复制：JNI 薄壳 src/clipboard.rs（B 档无考题）：
  `getSystemService("clipboard")` → `ClipData.newPlainText("kfm", text)`
  → `setPrimaryClip` → `Toast.makeText(已复制 N 字符).show()`。
  N = 字符数（chars().count()，非字节数）。

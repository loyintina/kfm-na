# 阅读页契约（BAR-170，2026-09-27 用户拍板·研究线亲做）

> 用户原话：「点击某个文件时，文件树关闭，中央页面是一个全屏的卡片页面，
> 里面是文本的阅读展示，如果是 md 会做 md 解析的渲染。这个页面需要滚动。
> 右上角加一个回到终端页面的按钮。」「它跟文件树是分开的两个插件。」
> **动阅读页前必读本文 + theme.md §2.5/§三 + md渲染器.md。**

## 定位：中央槽第一个非终端公民

- **第六面板公民 `Panel::Reader`**（声明序在 Demo 后）——全屏覆盖中央区，
  走 demo 页（BAR-166）同款面板栈机制：召唤/推回/缝/视口推移/z 序/三处
  涂装全链。终端在底下**不死**（tmux/PTY 照常跑，返回零成本）。
- **它是独立插件**：自己的状态核 `src/ui/reader_page.rs`（A 档纯逻辑），
  与文件树零共享状态；文件树只保留「发射文件点击」一个职责。
- **召唤口唯一** = 文件树文件行点击（改道：旧路进 cfg_page 模态查看器，
  新路 = `dismiss_top(FileTree)` + `summon_panel(Reader)` + 取数喂 reader
  核；行选中 select 行为保留）。会话池信件**不改道**（v1 仍走模态查看器，
  用户未点名，两容器共享同一渲染内核不算重复建设）。
- **关闭口双通道** = ①顶栏右上角「返回」钮（命中/涂装几何单源，modal
  关闭钮配方）②右缘拖拽推回（DismissReader，Demo 同款）。

## 状态核 reader_page.rs（A 档考题先行）

```
ReaderPage {
  path, name, kind: Md | Plain | Binary | Error(文案),
  text: String,            // 已取块拼接（md 排版的全量输入）
  eof: bool,               // 服务端 truncated=false 或到 CAP
  loading: bool,           // 有块在途
  scroll: i64,             // 当前滚动（眼手同尺单源）
  mem: Map<path, i64>,     // 每路径滚动记忆，MEM_CAP=128 满摘字典序最小
  epoch: u64,              // 代际（sig 维/脏帧唯一源）
}
```

- 几何单源（涂装/命中/滚动同读，学 demo_page 模式）：顶栏高
  `TOP_BAR_H = 110`（与文件树底栏同尺配方）、视口 = 页环内缘 − 顶栏、
  滚动上限 `scroll_max(total_h, view_h)`、**预取阈** = 滚动进内容尾
  1.5 视口内且 !eof 且 !loading → 取下一块。
- 分块：`CHUNK_MAX = 64KB`（代码常量名，对齐服务端 DEFAULT_MAX），
  拼进 text 即 epoch+1 触发重排版；**总量帽 2MB**（`MAX_CHUNKS = 32`
  块）到帽置 eof + 页脚「文件过大只显示前 2MB」一行。
- 打开流程：清旧态 → 记旧路径滚动进 mem → 取块① → NUL 探测（数据面
  自带）= binary → kind=Binary 占位「二进制文件不可读」；404/网络错 →
  Error 占位；文本 → 排版展示。
- 滚动记忆：开文件先查 mem 恢复 scroll（钳在当前 max 内）；关闭/换文件
  时回写。cap 策略与 filetree MEM_CAP 同款（确定性、可钉）。

## 数据面（最小侵入加法，旧契约零影响）

- `fsapi.rs` 加 `read_range_json_in(roots, rel, offset, len)` 纯函数
  （复用 resolve_in/text_prefix；seek(offset)+take(len+1)，NUL 探测与
  truncated 语义照旧，`truncated` 在此 = 「offset+len 之外还有数据」）。
- httpd.rs `Route::FsRead` 加 `offset` 字段（parse_offset 照 parse_max
  形状，缺省 0）+ main.rs handler 一行。
- `fs_fetch.rs` 加 `request_read_chunk(path, offset)` → 回执喂 reader 核
  （**不再进 cfg_page 查看器**——改道点二）。

## 排版与涂装（吃 BAR-169 三层管线，零平行实现）

- **一切文本过 md 管线**：.md → 全六样渲染；非 md → 同样喂
  `layout_md`（纯文本天然落段落块，围栏/标题语法不触发）——涂装路径
  只有一条，不为 plain 开第二条路。
- 正文排版 = `layout_md(text, content_w, md_style(), measure)`，
  `total_h` 喂滚动上限；涂装 = md_paint 规格（theme.md §2.5/§三），
  **文档原点 = 内容顶 − scroll**，纵裁剪 [内容顶, 视口底) 双裁纪律
  （查看器同款，防污染顶栏）。
- **页装修**：整页 CARD_PAGE_BG + paint_page_frame_ring 双色渐变环
  （四公民同配方）+ **顶栏**：文件名居中（draw_text_centered 双绘）
  + 右上角返回钮（paint_thin_frame + 居中「返回」）+ 顶栏底缘 1px
  c2→c1 渐变线 + **进度线**（顶栏底缘下 3px，accent 渐变，宽 =
  scroll/max × 内容宽，max=0 时不画）。
- sig 维（漏维 = 鬼影）：w/h/ime/bar_h/accent×2/reader epoch/scroll/
  md_style。三处涂装（GLES 槽烘焙/值守倒帧/软渲染兜底）同吃一份。

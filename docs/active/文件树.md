# 文件树页（na 左侧路由位）· BAR-165 施工档（2026-09-26 立）

> 定位：**文件树 = na 的第三个路由位页**（`ChromeSlot::FileTree`，左缘家），
> 复刻 kfmv4 原版手感。**规格本体 = 本文 + 原版真机截屏**
> `/root/na-assets/fstree-ref-20260926.jpg`（1260×2800）；nz 判据稿
> `/root/kfmv4/nz/docs/file-tree-v1-design.md` §七只作参数旁证（na 侧以本文
> 与实测锚点为准，冲突处照本文）。
> 契约归属：解析页.md 明写「文件树页不在解析契约——它是路由位不是解析位」，
> 故本页自理契约（本文即该契约）。

## 一、范围

**做**：只读文件树（懒加载展开/收起、滚动、选中光标框、底栏三盒）、
点文件 = 只读预览跳框（复用 BAR-163 查看器涂装）、远程相取数。
**不做（v1 明确排除）**：文件增删改、@ 引用、长按复制路径（nz §12 的件）、
搜索/模糊匹配、字符雨、卡片投影（平面化）。

## 二、数据面（na-server，BAR-165 同期落地）

| 端点 | 入参 | 出参 |
|---|---|---|
| `GET /api/fs/list` | `?dir=相对路径`（空 = 根） | `{ok,dir,entries:[{name,kind:"dir"\|"file",size,mtime}]}`，**只返直接子层** |
| `GET /api/fs/read` | `?path=相对路径&max=字节` | `{ok,path,binary,truncated,size,text?}`（默认 64KB 截断，NUL 探测二进制） |

- 纯函数核在 `crates/na-protocol/src/fsapi.rs`（两 crate 共享：服务端执行、
  客户端解码/编码对偶），路由在 `crates/na-server/src/httpd.rs`，执行在
  `main.rs`——**fs 工作走 `spawn_blocking`**（na-server 是
  `current_thread` 单线程运行时，同步 fs 会连坐 WS 终端流）。
- 安全模型（fail-closed，照 nz 语义）：默认根 `/root/00-Loyintina`（存在则
  用，否则 `$HOME`，`NA_FS_ROOTS` 冒号分隔可覆盖）；排除 `.obsidian`
  `.smart-env` `.trash` `node_modules` `.git` 与一切 `.` 开头名字；
  越界/不存在/非目录**同一条 404 同文案**（不透露存在性）；软链逃出根一律
  404（`canonicalize` 后前缀校验）。已声明差异：排序是 Rust 字节序（Node 是
  UTF-16 码元序，只在 U+10000 以上混排可见差）；列条目跟软链 stat（名字会
  出现、内容拿不到——与 nz 同）。
- 客户端：`src/fs_fetch.rs`（后台线程取数 → 灌 `ui::filetree` 状态核 →
  `take_dirty()`；查询值一律 `fsapi::pct_encode`）。
  **本地相降级判在客户端**（与 `/api/na/sys` 同构）：本地相给一行占位
  （「本地相：文件树不可用」），不发网络。

## 四、交互与手势

- **召唤/关闭**：左缘右滑（`panel_drag` 的 `SummonFileTree`，第 3 条公民）；
  底栏 **×** = 关页；页在顶时左滑 = 关（面板页裁决，本页不抢）。
- **行表**：`ft_touch` 槽（先量后锁）——起点在行表窗内才建槽；过 24px slop
  才滚（未过 = 点按候选，抬手进命中）；横向占优（`|dx| > 1.8|dy|`）整槽
  让回面板页；滚动吃增量、上界吃当下可视窗（状态核不揣屏寸）。
- **命中**（抬手）：**吃屏代快照**（`filetree::baked_snap`——命中唯一合法源
  = 屏上正显示的那一代，BAR-145 判例）。**三角带 = 开合；名字区 = 选中**——
这条切分吃原版截屏实拍证据（屏上选中的那一行是**目录**且没展开 ⇒ 名字区
  点按只选中、不顺手摊开）；文件行选中后另开只读预览跳框。
- **底栏**：眼 = 刷根层（`apply_root_list` 保已展开子树）；根名盒 v1 只读；
  × = 关页。
- **召唤沿拉一次根层**（不在顶 → 在顶）：懒加载只做一级，根层不刷 = 看不到
  新文件。
- **预览跳框**：状态住配置页（`CfgPage::open_viewer`，不复制第二份），涂装
  由文件树槽补画一次（配置槽在文件树页在顶时不烘焙）；抬手命中走既有的
  查看器族几何（`ui/modal.rs`），页无关。

## 五、接线（三处涂装同吃一份，漏一处 = 判卷空白）

| 路 | 烘焙点 | 位移 |
|---|---|---|
| GLES 槽烘焙 | `android_app.rs` `sigs.filetree.feed(...)` → `paint_ft_page_chrome` + `paint_ft_content` | 画布恒靠泊位（`x_shift = 0`），位移归合成期 |
| 值守倒帧（na-shot 判卷） | `gate.rs` 的 `Panel::FileTree` 支 | 原地整页画，喂当前缝采样 `ft_off` |
| 软渲染兜底 | `android_app.rs::paint_under` | 同上 |

- **脏帧 sig 十维**：`(w,h,ime,bar_h,acc_ft.c1,acc_ft.c2, 行表代, 滚动, 选中,
  动画簇)`——动画簇在动画期喂 `now_ms`（每帧都变 → 条件重烘接住），静止期
  恒 0（稳态零重烘）。漏一维 = 确定的鬼影。
- **活性探针**：`fx_spring::fx_frame_due` 第六路活性源 = 页内动画
  （抽屉/三角/光标）——只覆盖面板缝会漏掉「页停住而内容在动」= 动画零帧。

## 六、判卷

- A 档：`tests/filetree_spec.rs`（52 钉：几何/缩进锚点/状态机/命中/滚/动效
  端点）+ `src/termview.rs` 内 `ft_paint_smoke`（2 钉：落位与不炸，60+ 次
  涂装）+ `tests/ftree_wiring_spec.rs`（接线源码守卫 + 底栏命中纯函数钉）。
- C 档：**redroid 实拍对照原版截屏**（同宽 1260、高差 240px 硬顶——本容器
  `wm size` 锁死 2560，纵向对照须带补偿或只比同 y 起点局部）。
- 已知偏差（施工留档）：① 原版行带横向渐变 → na 纯色（用户裁决）；
  ② 展开时三角起点取点击时刻（快照带 tri 戳），收起也播 180ms；
  ③ 收起无「刚体下坠」（行即走，见 `collapse` 注）；
  ④ 行底圆角用「中段矩形 + 两端角带」近似容器块。

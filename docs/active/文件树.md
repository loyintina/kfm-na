## 一、范围

**做**：只读文件树（懒加载展开/收起、惯性滚动、选中光标框、底栏三盒）、
点文件 = 只读预览跳框（复用 BAR-163 查看器涂装）、远程相取数。
**不做（v1 明确排除）**：文件增删改、@ 引用、长按复制路径、搜索/模糊匹配、
字符雨、卡片投影（平面化）。

## 二、数据面（na-server 两端点）

| 端点 | 入参 | 出参 |
|---|---|---|
| `GET /api/fs/list` | `?dir=相对路径`（空 = 根） | `{ok,dir,entries:[{name,kind:"dir"\|"file",size,mtime}]}`，**只返直接子层** |
| `GET /api/fs/read` | `?path=相对路径&max=字节` | `{ok,path,binary,truncated,size,text?}`（默认 64KB 截断，NUL 探测二进制） |

- 纯函数核 `crates/na-protocol/src/fsapi.rs`（服务端执行 + 客户端编解码对偶），
  路由 `crates/na-server/src/httpd.rs`，执行 `main.rs`——**fs 走
  `spawn_blocking`**（na-server 是 `current_thread` 单线程，同步 fs 会连坐 WS）。
- **缺省根 = `/root`**（症⑦改约）：不依赖 `HOME`（systemd 无 HOME 时旧实现
  落到 `/`，真机打开 44 条系统目录）；`NA_FS_ROOTS` 冒号分隔覆盖保留；
  排除 `.obsidian .smart-env .trash node_modules .git` 与一切点开头；
  越界/不存在/非目录**同一条 404 同文案**；软链逃出根 404。
- 客户端 `src/fs_fetch.rs`（后台线程取数 → 状态核 → `take_dirty()`；
  查询值 `pct_encode`）；**本地相降级判在客户端**（本地相给占位行）。

## 四、交互与手势

- **召唤/关闭**：左缘右滑（`panel_drag` 的 `SummonFileTree`）；底栏 × = 关页；
  页在顶时左滑 = 关（面板页裁决）。
- **行表手势**（`ft_touch` 槽）：起手建 `scroll::TouchScroll`（新触摸落地
  **取消在飞甩尾**）；过 24px slop 才滚（未过 = 点按候选）；横向占优
  （`|dx| > 1.8|dy|`）整槽让回面板页；拖动吃 `moved_px_at`（像素位移，
  自带 slop 与速度采样）；抬手 `was_tap()` 真 = 命中分流、假 =
  `fling_on_release()` 交接 `scroll::Fling`，帧泵 `Fling::step` 按真实间隔
  付位移（每帧 ×0.96 衰减，启动阈 0.5 / 燃尽阈 0.3 px/帧）；**触底/触史顶
  即燃尽**（实滚量 ≠ 请求量即杀）。全部复用 `src/scroll.rs` 的封存件。
- **命中**（抬手）：吃**屏代快照**（`filetree::baked_snap`——命中唯一合法源
  = 屏上正显示那一代，BAR-145 判例）。**目录行整行 = 开合、文件行 =
  选中/预览**（症⑤改回原版；真机 logcat 20+ 次点按零 toggle 为证。
  旧口径「三角带 Toggle / 名字区 选中」是把原版截屏的「选中未展开正常态」
  误读成口径证据）；三角只是**状态指示**，行内任意 x 同义，**无死区**。
- **底栏**：眼 = 刷根层（`apply_root_list` 保已展开子树）；根名盒 v1 只读；
  × = 关页。召唤沿拉一次根层。
- **预览跳框**：状态住配置页（`CfgPage::open_viewer`），涂装由文件树槽
  补画一次；抬手命中走既有查看器族几何。

## 五、接线（三处涂装同吃一份，漏一处 = 判卷空白）

| 路 | 烘焙点 | 位移 |
|---|---|---|
| GLES 槽烘焙 | `android_app.rs` `sigs.filetree.feed(...)` → chrome + `paint_ft_content` | 画布恒靠泊位（`x_shift = 0`） |
| 值守倒帧（na-shot 判卷） | `gate.rs` 的 `Panel::FileTree` 支 | 原地整页画，喂当前缝采样 |
| 软渲染兜底 | `android_app.rs::paint_under` | 同上 |

- **脏帧 sig 十维**：`(w,h,ime,bar_h,acc_ft.c1,acc_ft.c2, 行表代, 滚动, 选中,
  动画簇)`——动画簇在动画期喂 `now_ms`，静止期恒 0。漏一维 = 确定的鬼影。
- **活性探针**（`fx_spring::fx_frame_due`）：文件树页内动画（抽屉/三角/光标）
  一路 + **甩尾在飞**一路（`note_ft_fling_live` 全局旗——甩尾机住壳 App，
  `ui` 层反向依赖 android_app 编不过，故用旗与 `LAST_FRAME_MS` 同规）。

## 七、打回重做修订（2026-09-27 用户终验：六症 + 一定罪）

| # | 病症（用户原话/定罪） | 修订 |
|---|---|---|
| ① | 字号太小：`FT_TEXT_PX=34`、三角 20×22 比例失调 | 文字 **44**（原版实测字高 32~33 的放大档）、三角 **26×28**（基形 13×21 等比 ×1.3）；常量收拢在 `termview.rs`（`FT_TEXT_PX`/`filetree::TRI_W/TRI_H`） |
| ② | 行带与光标右缘留空 | **光标右缘扩到行表窗全宽**（`bx1 = g.x1`；行带本就全宽）。开口框右边不封口，下线一路拖到窗右缘 |
| ③ | 三角硬编码 teal | 三角/光标/底栏件**全部改吃页 accent 渐变同源采样**（`ring_gradient_rgb`，帧尺 = 页环同一把 135° 尺：原点 0,0 分母 (w−1)+(h−1)）——原版那格 teal 是**那次召唤随机到的 accent**，`CHEVRON_RGB` 降级为实测留档常量 |
| ④ | 光标是新画的无圆角版 | **换封存件 `paint_open_cursor`**（termview.rs:1303，comp_registry「功能光标开口框·封存件复活展出」——封存时就注明「待文件树光标复用」）：左强调线 + **SDF 圆角弧** + 顶底发丝 + accent 底垫 α15%，线色逐像素吃页 accent 渐变 |
| ⑤ | 点目录行不开合（误读截屏当口径） | **目录行整行 = 开合**（三角只是状态指示）；文件行 = 选中/预览；三角盒与名字区之间的**死区消灭**（`hit`/`hit_snap` 不再看 x） |
| ⑥ | 滚动是手写增量跟手，没惯性 | **接 `src/scroll.rs` 封存惯性件**：`TouchScroll::moved_px_at`（拖动采样）+ `fling_on_release`（抬手交接）+ `Fling::step`（帧泵区间几何级数，每帧 ×0.96，启动阈 0.5/燃尽阈 0.3）；新触摸取消、触底即燃尽；进活性探针。手写增量跟手**废弃** |
| ⑦ | 缺省根落到 `/`（systemd 无 HOME） | 缺省根定死 **`/root`**，不依赖 `HOME`；`NA_FS_ROOTS` 覆盖保留；旧钉改新约 + 补「无 HOME 缺省=/root」钉 |

**明确不动**（用户已裁）：行带 c1/c2 奇偶交替用色保留；左强调边宽度与行带
α 公式本单不动（待真机再看）。

# 插件档案 002 · 选择系统（输入栏文本选择 + 复制粘贴菜单）

> 2026-09-02 立项（用户拍板：先写设计文档再开工）。
> 定位：输入栏线的下一自然延伸——把「只能打字+光标」升级到「能选、能复制、能粘贴」的
> 标准移动端文本编辑体验。本文档是交互细节、状态机、边界规则、验收判据的唯一源。
>
> 活文档纪律：后续对选择系统的任何修改、事故、调参追加到「闭环后迭代」一节。

## 起点：要解决什么问题

当前输入栏只有光标和定位柄，没有选区。用户无法：
- 复制已输入的文字到别处；
- 删除/替换一段文字；
- 把别处复制的内容贴进来；
- 快速全选后清空或替换。

这是移动端文本编辑的「基础尊严」功能，必须在进入 AI 对话页/浮层之前补齐。

## 范围与边界

### 做（MVP）
1. 输入栏内**长按进入选择模式**。
2. **选区双锚点**（左/右），可拖动调整范围。
3. **选中文字高亮**（品牌色半透明底）。
4. 弹出**操作菜单**：复制 / 剪切 / 粘贴 / 全选。
5. 与系统剪贴板打通（Android `ClipboardManager`）。
6. 选择状态与现有输入栏状态（cursor/composing/handle/follow/scroll）互斥规则。

### 不做（明确延后）
- 终端网格选择（终端是另一套文本模型）。
- 双击选词 / 三击选段（可二期加，先保长按+手柄稳定）。
- 富文本 / 样式粘贴（只处理纯文本 `ClipData.Item`）。
- 悬浮工具栏 / 自定义菜单项（先系统标准四键）。
- 选择历史 / 多剪贴板。
- TalkBack / 无障碍（二期）。

## 状态机

选择系统新增状态核字段（全部挂在 `InputBarState::Inner`）：

```rust
selection_start: usize,   // 选区左锚点（char 下标，含）
selection_end: usize,     // 选区右锚点（char 下标，不含）
selecting: bool,          // 是否处于选择模式
sel_anchor: SelAnchor,    // 当前被拖动的锚点：None / Left / Right
```

与既有状态的关系：

| 既有状态 | 选择模式下的语义 |
|---|---|
| `cursor` | 当 `selecting=false` 时照旧；当 `selecting=true` 时 `cursor = selection_end`，退出选择模式后光标落在选区尾 |
| `handle` | 选择模式下隐藏蓝色定位柄，改为显示双锚点 |
| `composing` | 进入选择模式前先 `finish_composing`（组合文本落真字），避免虚拟拼音参与选区 |
| `follow` | 拖动锚点导致 cursor 移动时，按编辑操作规则回尾锚（follow=1） |
| `scroll_px` | 锚点拖出 field 上下边界时，自动滚动视口（同拖动滚动规则） |

### 状态迁移表

| 事件 | 当前状态 | 下一状态 | 规则与禁令 |
|---|---|---|---|
| 长按文本区（≥SELECT_LONG_PRESS_MS=400ms，位移<slop） | 普通编辑 | 选择模式 | `selection_start = selection_end = 点按 char 下标`，`selecting=true`；**禁令**：组合态必须先 finish；**禁令**：长按期间若位移≥slop则判为拖动滚动，不进入选择 |
| 拖动左锚点 | 选择模式 | 选择模式 | `selection_start = min(锚点位置, selection_end)`；锚点不能越过右锚点 |
| 拖动右锚点 | 选择模式 | 选择模式 | `selection_end = max(锚点位置, selection_start)`；锚点不能越过左锚点 |
| 点选区外文本区（短按） | 选择模式 | 普通编辑 | 退出选择，`cursor=点按位置`，`handle=1` |
| 点选区内文本 | 选择模式 | 选择模式 | 不退出，仅重定位菜单（若菜单已显示） |
| 点「复制」 | 选择模式 | 普通编辑 | 文本写入剪贴板；退出选择，`cursor=selection_end`，`handle=0` |
| 点「剪切」 | 选择模式 | 普通编辑 | 写入剪贴板 + 删除选区文字；退出选择，`cursor=selection_start`，`handle=0` |
| 点「粘贴」 | 任意 | 普通编辑 | 有选区则替换选区；无选区则在 cursor 处插入；退出选择 |
| 点「全选」 | 任意 | 选择模式 | `selection_start=0, selection_end=text.len()`，菜单保持 |
| 点发送钮 / Enter | 选择模式 | 普通编辑 | 先退出选择（不剪切），再执行 submit |
| Esc / 点终端区 | 选择模式 | 普通编辑 | 直接退出选择 |
| 打字（IME commit / 字符键） | 选择模式 | 普通编辑 | 先删除选区，再插入新字符 |
| 退格 | 选择模式 | 普通编辑 | 删除整个选区 |

## 视觉规格

### 选中高亮
- 底色：`theme.bar.select_bg`（默认品牌蓝 `#0066FF` α=0.35，先取 term 侧 `SELECT_BG` 迁移）。
- 范围：从 `selection_start` 对应字左边界到 `selection_end` 对应字左边界。
- 高度：与文字行高同高（`LINE_STEP_PX`）。
- 圆角：4px（与光标柄同族）。

### 双锚点手柄
- 形状：与蓝色定位柄同款「上尖三角+正方承载」，但尺寸缩小到 28×28（选择锚点比光标柄小）。
- 颜色：品牌蓝 `SELECT_BG`（与定位柄一致，保持视觉同族）。
- 位置：
  - 左锚点：尖朝上，底边贴选区首字底边，水平中心对齐首字左边界。
  - 右锚点：尖朝上，底边贴选区末字底边，水平中心对齐末字右边界。
- 热区：以锚点为中心 48×48，便于单指拖动。

### 操作菜单
- 触发：进入选择模式后 150ms 淡入（硬切也可以，看实现复杂度）。
- 位置：优先显示在选区上方；若选区上方空间不足（如贴键盘），则显示在选区下方。
- 形态：水平圆角条，含四个文字按钮：「全选 | 复制 | 剪切 | 粘贴」。
- 未启用项灰显：剪贴板为空时「粘贴」灰显；无选区时「复制/剪切」灰显。
- 颜色：背景 `theme.bar.menu_bg`（近黑半透明），文字 `theme.bar.menu_text`，禁用 `theme.bar.menu_disabled`。

## 与系统剪贴板交互

### Android 侧
- Java：`ClipboardManager` + `ClipData.newPlainText("kfm-na", text)`。
- JNI 两入口（加到 `android/java/dev/kfm/na/MainActivity.java`）：
  - `nativeClipboardSet(String text)`：复制/剪切时调用。
  - `nativeClipboardGet()`：粘贴时调用，返回当前纯文本或空串。
- Rust 侧：`android_app.rs` 接到 JNI 回调后，走 `InputBarState::paste(text)` 插入或替换。

### 纯文本契约
- 只读/写 `ClipData.Item` 的 `getText()`；遇到 HTML/URI/intent 时忽略，视为空。
- 粘贴最大长度限制：先不设，未来若发现系统剪贴板里有几 MB 文本导致卡，再加 4096 字符闸。

## 触摸手势仲裁

输入栏文本区同一套触摸流里已经存在：
- 短按 → 定位光标
- 长按 → 进入选择
- 拖动 ≥slop → 滚动视口
- 锚点拖动 → 调整选区

仲裁规则（按优先级）：
1. **Down 时命中锚点热区** → 进入锚点拖动模式，即使长按也不判滚动。
2. **Down 在文本区，Moved ≥ TAP_SLOP 且未达长按时间** → 滚动视口（保持现有行为）。
3. **Down 在文本区，停留 ≥ SELECT_LONG_PRESS_MS 且 Moved < TAP_SLOP** → 进入选择模式。
4. **Down 后快速抬手（< SELECT_LONG_PRESS_MS，Moved < TAP_SLOP）** → 短按定位光标并退出选择。

锚点拖动 vs 文本滚动：锚点拖到 field 上/下边缘 12px 内时，按滚动速度（每秒 2 行）自动滚屏，让选区能跨出视口。

## 状态核接口新增

```rust
impl InputBarState {
    /// 进入选择模式；若已有组合态先 finish
    pub fn enter_selection(&self, anchor: usize);

    /// 设置左锚点（被拖动的左柄）
    pub fn set_selection_start(&self, pos: usize);

    /// 设置右锚点（被拖动的右柄）
    pub fn set_selection_end(&self, pos: usize);

    /// 退出选择模式，cursor 落在 selection_end
    pub fn clear_selection(&self);

    /// 全选
    pub fn select_all(&self);

    /// 返回当前选区文本；无选区返回 None
    pub fn selected_text(&self) -> Option<String>;

    /// 删除选区文字；返回是否发生了删除
    pub fn delete_selection(&self) -> bool;

    /// 在 cursor/选区处插入文本；有选区先替换
    pub fn insert_or_replace(&self, s: &str);
}
```

渲染层 `render_inputbar` 新增：
- 若 `selecting` 为真，在对应字上画高亮矩形。
- 若 `selecting` 为真，画双锚点手柄（锚点出窗则不画，不冒充）。
- 菜单由 `android_app.rs` 在触摸事件后决定是否弹出；渲染层只负责选区+锚点，菜单走 Android View 浮层或自绘条带（先选简单方案：自绘条带，避免 Activity 层级污染）。

## bar-inject 新增指令

为了 AI/遥控轨道能测试选择系统，新增：
- `select <start> <end>`：进入选择模式并设置选区。
- `select-all`：全选。
- `copy` / `cut` / `paste`：执行对应动作。
- `unselect`：退出选择模式。

## 判卷与验收

### A 档纯逻辑考题（服务器可跑）
1. `selection_set_start_does_not_cross_end`：左锚点拖动不能越过右锚点。
2. `selection_delete_replaces_text`：删除选区后文字与光标位置正确。
3. `selection_insert_replaces_selection`：有选区时插入先删后插。
4. `display_text_with_selection`：组合态+选区同时存在非法，进入选择时 composing 被 finish。

### B 档渲染考题（需 TermView 字体）
5. `selection_highlight_pixels`：选区文字底有品牌蓝高亮像素。
6. `selection_anchors_blink_independent_of_caret`：锚点稳显，不随光标闪烁。
7. `selection_menu_appears`：进入选择后菜单像素出现。

### C 档装机实拍手检
8. 长按普通文本 → 出现高亮+双锚点+菜单。
9. 拖动左/右锚点 → 选区实时伸缩，不闪退。
10. 复制 → 切换应用能粘贴出相同文字。
11. 剪切 → 原文删除 + 剪贴板有内容。
12. 粘贴 → 在 cursor/选区处正确插入。
13. 全选 → 全部文字高亮。
14. 选择模式下打字 → 选区被替换。

## 风险与已决项

1. **菜单实现路径**：
   - **方案 A（已定）**：自绘菜单条带在 `render_inputbar` 内，与选区同帧，不新增 Android View。
   - 质量闸门：实拍验收必须达到「一看就是专业 App 的选择菜单」；若自绘版看着像半成品，回炉或切方案 B。

2. **长按时间**：**400ms**（Android 系统默认值）。

3. **锚点尺寸**：**28×28 视觉 + 48×48 热区**。

4. **菜单项顺序**：**「全选 | 复制 | 剪切 | 粘贴」**。

# 调试闸门 —— 看见 + 读懂 + 动手（2026-08-24 立，用户拍板三件套）

> 定位：agent 自助调试 na 的完整闭环，也是眼睛/手 v2 的地基
> （dump_text = 网格眼睛胚胎，keys-in 注入 = 手的胚胎）。
> 实现：src/gate.rs（通道 + 值守线程 + 共享注册表）；
> 考题：tests/gate_spec.rs + termview_spec.rs 的 spec_dump_text。

## 一、为什么存在

调试 na 不能靠用户当手和眼睛。闸门让 agent 从服务器侧（8024 ssh 进 na 沙箱）
独立完成：看画面（截图）、读内容（文本）、动手（注入按键）——应用退后台
也照常工作（BAR-029 保活 + 值守线程不归事件循环管）。

## 二、通道表（文件即信号，目录 = $PREFIX/tmp）

| 触发文件 | 动作 | 产出 | 服务器侧脚本 |
|---|---|---|---|
| `shot-req` | 锁终端离屏光栅化当前帧 | `shot.rgb` + `shot.dim` | `scripts/na-shot.sh` |
| `text-req` | 锁终端导当前视野纯文本 | `screen.txt` | `scripts/na-text.sh` |
| `keys-in` | 内容当裸字节发活跃会话 PTY | 无（注入即消费） | `scripts/na-type.sh 'cmd\r'` |
| `ping-req` | 回一行看门狗判决到 `ping-res` | `ping-res` | `scripts/na-ping.sh` |
| `restart-req` | 遗言直报后 `exit(0)` 体面退出 | 无（Termux 侧拉回） | `scripts/na-restart.sh` |
| `trace-req` | 行踪环全量落 `trace.txt` | `trace.txt` | `scripts/na-trace.sh [行数]` |
| `stats-req` | 统计快照落 `stats-res` | `stats-res` | `scripts/na-stats.sh` |
| `touch-in` | 触摸脚本解析入队，主循环与真手指同入口执行 | 无（注入即消费） | `scripts/na-touch.sh 'scroll 3'` |

- 值守线程 300ms 一轮八查（`spawn_gate_watcher`，android_main 起一次）。
- **restart-req = 热更闭环的重启腿**（2026-08-26 定）：值守线程就地
  `exit(0)`，不经过事件循环——挂起态也杀得死。进程死了由 Termux 侧
  `am start` 拉回（na-restart.sh 一键：触发→等 8024 断连→拉回→等新
  boot 报告→na-ping 判卷）。若进程被 ROM 冻结（线程不进片、触发文件
  没人看），拉回时 android_main 重跑，BAR-037 防御接住：遗言 +
  `exit(0)` 让位，na-restart.sh 补第二次 `am start` 起全新进程。
  熄屏/锁屏时 `am start` 可能被系统挡，脚本会提示手动点图标。
- **keys-in 半写防护**：写入端先写 `keys-in.new` 再 `mv`（rename 原子）；
  消费端 rename 取走再读再删。空文件 = 无操作但照样消费。
- **na-type.sh 字节语义**：`printf '%b'` 把 `\r`/`\x03` 翻成真字节再发
  （2026-08-24 实拍：`%s` 把 `\r` 当字面两字符，命令全堆提示符零执行——
  链路四环全活，病在最后一厘米的编码；钉 = scripts/test-na-type-bytes.sh）。
- text dump = 当前视野（含滚动位置，对齐「所见」），v1 不导 scrollback。
- shot 后台倒出的是终端网格本体（快捷键行/放大镜是 UI 装帧，不进后台视野）。

## 三、有意的限制（不是缺陷）

- 注入是**裸字节**直达活跃会话 PTY：Ctrl 组合写控制字节（`\x03` = Ctrl+C）；
  Ctrl-]（`\x1d`）会话切换是 UI 层逻辑，闸门不支持；快捷键行修饰键粘滞同理。
- 会话死亡时 `send` 静默吞（`SessionRouter::send` 语义不动）；闸门注入走
  `send_checked` 回执，drain/登记/send 三环结果各留一行 `gate` 报告——
  哪环断了在 field-reports 里看得见（2026-08-24 keys-in 静默丢失案后的判案纪律）。
- 软键盘/系统弹窗不在帧缓冲里，shot 拍不到。

## 四、共享与锁序（改动面最大的部分）

- 终端 `Arc<Mutex<Box<dyn TermEmu>>>`（别名 gate::SharedTerm）：UI 渲染与
  值守线程共享；`draw_frame` 每帧 `note_frame_size` 记账供后台取尺寸。
- 路由 `Arc<Mutex<SessionRouter>>`（gate::SharedRouter）：keys-in 注入入口。
  切换/断线重连都经 router 方法换内脏，Arc 身份不变——装配时注册一次，
  永远新鲜，不存在「注到死会话」的陈旧句柄。
- 锁序约定：值守线程锁 term/router 都单独持有不嵌套；UI 侧只有
  term→router 方向（滚轮上报站点），无反向 → 无环。

## 五、会话泵（Output 数据面分家，2026-08-24）

分家前：PTY 输出走 `SessionEvent::Output` 进 UI 事件队列，挂起态事件
循环不抽干 → 网格冻结，keys-in 注入真执行了、闸门读屏却读到旧画面
（na-type 修复案实证链的最后一环）。

分家后：`gate::SessionPump` 是全部会话入向通道的**唯一消费者**——

- **活跃方 Output**：谁 pump 谁喂共享终端。双 caller：UI 每圈一次
  （前台零延迟）+ 值守线程 300ms 一轮（后台网格照新，闸门眼睛实时）。
- **待机方 Output**：进泵的 replay 缓存（按名，帽 `REPLAY_CAP_BYTES`
  =256KB，爆量丢最旧——旧制 mpsc 无界积压的暗雷顺手排掉）；Ctrl-]
  切换时壳 `pump_take_replay` 取走补屏。
- **控制事件**（Opened/Exited/Failed）：泵一粒不判，按名带进控制队列，
  壳每圈 `pump_take_control` 取走记健康牌/触发重连（语义同旧制）。
- **重连换心脏**：`pump_register` 同名登记 = 顶掉旧通道 + 清该名
  replay（旧 shell 遗物不喂新会话）。
- 锁序追加：`pump→term`（sink 回调内单方向）；pump 与 router 互不嵌套。
- 考题：`tests/session_pump_spec.rs` 7 题（路由/缓存/限量/换心脏全钉）。

## 六、飞行记录仪（确定性回放，2026-08-24 与用户定）

一切会话 Output 经泵的 rec 见证回调**全量带名落带**（与路由无关），
尺寸事件同带——落盘 `flight-rec.bin`（闸门目录，2MB 帽保新丢旧，
单条超帽也留最新一条 = 案发点；截尾容忍：进程死在半条记录不毁前文）。
**开机轮换**（BAR-034）：冷启动时旧带整体改名 `flight-rec.prev.bin`
保全（坠机现场不丢，只保最近一世），新带写魔数起新时间线——记录带
代表当前进程的屏幕真相，跨重启追加会让旧时间线堆到新屏头顶，
「回放末屏 = 读屏」判卷永远对不上（2026-08-25 实拍）。

- 格式：魔数 `KFMREC01\n` + 记录流（`[u64 ts][u8 kind][u8 nlen][name]
  [u32 a][u32 b][u32 len][payload]`；kind 1=Output，2=Resize）。
  纯函数层 `rec_encode/rec_decode_all/rec_compact`，考题 rec_spec 5 题。
- tap 纪律：入队即返回（零 IO），写盘/压缩全在记录仪线程——观测通道
  不拖垮本体（与 report 同铁律）。
- **host 回放器** `src/bin/na-replay.rs`：记录喂进同一台 TermView 复现
  末屏（文本级，字体无关）。一键 `scripts/na-replay.sh [会话名]` =
  拉回 + 回放。渲染 bug 从此不用碰手机就能慢看。
- v1 边界：不录输入流（输入的效果在输出回显里已可见）；像素级回放
  留待需要时（生产内嵌字体 host 可载，无硬障碍）。
- 上机提示横幅（HELP_BANNER）只 feed 视图不进 PTY，泵见证不到，
  故在 feed 处单独 tap 一条（按启动时活跃名）——上了屏就是屏幕事实，
  不记则「回放末屏 = 读屏」判卷每次冷启动都差那几行（2026-08-25 实拍）。

## 八、死亡观测（2026-08-25 与用户定：panic 落盘 + loop 看门狗）

记录仪答「死前屏幕什么样」，本节答「怎么死的」——此前 panic 信息进
logcat 黑洞（线程 panic 无声无息），循环卡死/冬眠靠人肉推理
（blackout 案、BAR-029 冻结案都是硬查出来的）。

- **panic 落盘**:`install_panic_hook`（android_main 挂）三件套——
  ①追加写闸门目录 `panic.log`（主道，进程死了现场还在）;②report
  异步直报（辅，冲洗队列随进程死会丢）;③链默认钩子（logcat 照走）。
  行格式钉死：`unix=秒 thread=名 at=文件:行 msg=消息`，消息内换行
  压成 ␤，一行一案。线程 panic 同样收（记录仪/值守线程若死不再无声）。
- **loop 看门狗**:`about_to_wait` 每圈盖心跳戳（降频泵 4ms 节拍，前台
  正常 ≥250 圈/s——2026-08-26 从全速空转降频，57k/s 白烧被砍）。值守
  线程每轮比龄期：> `LOOP_STALL_MS`(3s)= 卡死/冬眠，
  迁移时写 `loop-stall.log` 一行（STALL/RECOVERED/SUSPEND）并 report 直报。
  纯被动——不要 proxy 探针（挂起态 proxy 送不达，实锤过的弯路）。
  **前台门控**(BAR-036)：挂起态循环合法停跳，`resumed/suspended`
  喂 `APP_FOREGROUND`，退后台 = 看门狗休假不判（ping 答 background)。
  判决收敛成纯函数 `watch_verdict` 四态，考题钉死。
- **随查**:`ping-req` → `ping-res`(alive beat_age=Nms / stall /
  未起跳），一键 `scripts/na-ping.sh`。
- 与既有心跳的关系：report 的 3s 进程心跳答「进程活着吗」，看门狗答
  「事件循环在转吗」——进程活着但循环卡死正是 blackout 类病的长相。

## 九、行踪环 + 运行时统计（2026-08-26 与用户定：自观测第二块）

第八节答「怎么死的」，本块答两件事：**「死前/刚才发生了什么」**
（事件流）和**「现在什么状态」**（计数器）。

- **trace ring（`src/trace.rs`）**：report 流的本地滚动副本。tap 点在
  `report/report_sync/report_sync_once` 三个上报咽喉——一处旁路，全网
  事件（boot/death/loop 迁移/gate/ws/session）自动入环，调用点零改动。
  环帽 256，纯内存零 IO；两类周期心跳（alive 3s / loop 10s 周期戳）
  由 `should_trace` 滤掉——它们是活性探针不是事件，入环只会稀释信号。
  取用两路：活着时 `trace-req` → `trace.txt` 全量随查
  （`scripts/na-trace.sh [行数]`）；panic 时钩子自动落末 64 行进
  `panic-trace.txt`（覆写制，最新一案的现场）。与 field-reports 的
  分工：后者过 HTTP+隧道、进程暴死队列随殉；本环在本地，死了也能捞。
- **stats-req（`gate.rs stats_answer`）**：`stats-req` → `stats-res`
  快照，key=value 一行一项：uptime/前台态/循环龄期/帧计数/泵调用与
  字节累计/闸门四通道动作计数/活跃会话与名单。计数点全在热路径上，
  AtomicU64 加一，零锁零分配。一键 `scripts/na-stats.sh`。
- 行格式双双钉死（`[+00012345ms stage] msg` / key=value），考题
  `tests/trace_spec.rs` 4 道（满帽挤旧保序/行格式/心跳过滤/stats
  格式）。

## 十、资源画像 + 一键收尸包（2026-08-27 与用户定：自观测第三块）

第九块答「状态计数」，本块把计数升级成**画像**：不只知道干了几次，
还知道每次多贵、机器多累。

- **帧耗时**:`draw_frame` 起手记 `Instant`,present 后报
  `note_draw(elapsed)`——stats 出 `draw_avg_ms`(total/frames,
  防除零）与 `draw_max_ms`(`fetch_max`)。卡不卡，直接看帧账。
- **CPU/内存**:stats 快照里读 `/proc/self/stat`(utime+stime
  jiffies,comm 可含括号空格，必须从最后一个 `)` 后切）和
  `/proc/self/status` 的 `VmRSS`——`cpu_jiffies` / `rss_kb`。
  读取失败静默给 0（观测铁律：不许反咬业务）。两个解析器是纯函数，
  考题钉死（含带括号 comm 样本、残缺行不 panic)。
- **会话分桶吞吐**：泵 rec 回调按会话名记账，`bytes_local` /
  `bytes_remote` / `bytes_other`——谁在吃流量一目了然。
- **会话死亡计数**:`on_slot_dead` 每死一次 `session_deaths`+1——
  重连/重孵频度 = 网络与 PTY 健康的温度计。
- **一键收尸包 `scripts/na-autopsy.sh [备注]`**：触发 trace/stats
  落盘 → 把 panic.log / panic-trace.txt / loop-stall.log /
  trace.txt / stats-res / loader-pick / flight-rec.bin 全量拉回
  `autopsy/<时间戳>[-备注]/` → 打印摘要（stats 全文 + panic 末行 +
  trace 末五行）。装机异常一条命令收齐现场，缺档不致命。
- 考题：`tests/trace_spec.rs` 增至 6 道（stats 新字段格式、
  draw_avg 防除零、stat/status 解析各一）。

## 十一、排障闭环 + 逃逸条款 + 观测矩阵（2026-08-27 与用户定）

前十节是「武器库」，本节是「战法与纪律」：**bug 不再是负债，
是观测系统的需求输入**——每个打不死的 bug 结案时必须留下永久武器。

### 闭环六步（每个 bug 的标准走位）

1. **定位**:`na-autopsy.sh` 收现场（trace/stats/panic 一把齐）;
2. **复现**：用闸门注入/回放复现用户描述（排障手册速查表选尺）;
3. **找因**：钉到函数级，先写失败考题再动代码；
4. **测试**：考题红→绿，chain 全绿；
5. **修复送机**：热更（`na-push-so.sh`）或重打 APK(build-on-phone);
6. **同法复验**：用第 2 步**同一把尺**再量一遍——「我觉得好了」不算数。
   机械面（盲测洞⑤补）：案卷「判卷法」栏必须是**可复跑的命令序列**
   （复现脚本填充后退出码即判卷：0=愈，非零=未愈）;C 档感官判卷
   例外，但须写明实拍步骤清单，不许只写「实拍看看」。

### 逃逸条款（硬纪律）

bug 满足任一条件——**看不见现场 / 一修不好 / 复现不了**——
不许以「改好了」结案。结案硬条件是留下至少一件永久资产：

- 一个新观测点（计数器/trace 段/通道）;或
- 一道回归考题（tests/ 带 BAR 编号）;或
- 一个可复用脚本（scripts/,头部注释写全）。

修复只是止血，结晶才是结案。开案用 `scripts/na-case.sh`
（收尸 + 案卷骨架 + 复现模板一条命令），案卷六栏模板在 bugs.md 案卷区。

### 观测矩阵（「看不见」的分类账）

每逃逸一次填一格；接 bug 先查哪格空，直奔空格补观测。

## 十二、触摸注入（2026-08-27 与用户定：观测矩阵输入侧空格销案）

手势类 bug（滚动/缩放/长按选择/快捷键行命中）此前是唯一没有复现腿
的类别——keys-in 注的是 PTY 字节，够不着 UI 手势层，回回要用户当手。
本块把触摸参数化，补全「截图→滚动→再截图」路径的操作半。

- **协议**:`touch-in` 文件一行一指令——`tap x y` /
  `down|move|up x y [id]`（默认指 id=90）/ `scroll ±n`（语法糖，
  n>0 看历史 = 手指下扫，scroll.rs 契约 y 增大 = 正行数）/
  `sleep ms`（封顶 10s，防写错脚本焊死节拍器）。空行/# 注释跳过，
  坏行收编上报不炸解析。解析器纯函数，A 档考题
  `tests/touch_spec.rs` 4 道（语法/坏行分流/封顶/整段）。
  轻点阈值**含边**（AOSP touchSlop 惯例：位移恰好到 TAP_SLOP_PX
  仍算点按期）——2026-08-27 变异抽检首只存活体实锤此处无定义后
  补钉（scroll_spec 边界题）。
- **同入口原则（本块的灵魂）**：原 `WindowEvent::Touch` 臂 278 行
  机械搬家成 `handle_touch(id, x, y, phase)`，真手指与注入双喂——
  注入复现 = 真手势复现，不是「另一条长得相似的路」。搬家全程
  行界切片 + 词边界断言 + 编译验证，零逻辑改动。
- **执行器**:App 侧 `drain_touch_in`(about_to_wait 每圈）——
  Sleep 挂起节拍（长按选择等时序手势可写），Scroll 按真实格高

## 十三、坠机信号 + 异常自报 + 历史水位（2026-08-27 与用户定：自观测第四块）

前三块把「人来查」做全了，本块补三个角：native 崩溃留字、异常反
方向找人、趋势有曲线。考题 `tests/selfwatch_spec.rs` 9 道。

- **①信号级坠机记录（`src/crash.rs`)**:panic 钩子管 Rust 层，
  SIGSEGV/SIGBUS/SIGILL/SIGABRT 绕过它（jni/字体光栅化段错误，
  进程直接没）。本模块装 last-gasp 信号处理器：异步信号安全
  （只 write 到预开 fd，零分配零锁），写一行
  `SIGNAL sig=11 addr=0xdeadbeef` 进 panic.log 后 re-raise 交还
  系统（内核 tombstone 照留，不截胡）。`SIGURG` 是装机判卷探针：
  写行后**继续活**——`kill -URG $(cat .../na.pid)` → panic.log
  应多一行且进程不死，信号路径端到端可装机验证。行格式手写
  十/十六进制进栈缓冲（handler 里 format! 会分配，不许用）。
- **②异常自报告警（gate.rs `alert_check` 纯函数）**：方向反过来，
  不等人查——值守每 3s 对快照过三规则，越线走
  `report("alert", ...)`（自动进 trace 环 + field-reports.log):
  帧耗 >100ms 且是新峰值；RSS 越 512MB 绝线或 5 分钟窗净涨 >64MB
  （冷却 10min)；会话死亡 5 分钟窗新增 ≥3（冷却 5min)。状态机
  `AlertState` 全在参数里，考题传死数全程确定性。只报「该有人
  看一眼」级别，误报宁可少。
- **③stats 历史水位环**：趋势类 bug（越来越慢/内存爬坡）单点快照
  看不出坡。值守每 30s 压一张快照进环（帽 48 ≈ 24 分钟回望窗），
  通道九 `history-req` → `history.txt` 每张一行紧凑格式，
  `scripts/na-history.sh` 一拉一条曲线，awk 取列即可画。
- **装机判卷法**:kill -URG 探针验①;`na-history.sh` 看快照累积
  验③;②只能验证「不误报」（不主动制造异常），诚实标注。

## 十五、故障注入探针族（2026-08-27 与用户定：自我测试缺口③）

自观测（一~十三）答「看得见」，真机回归（§十四）答「结案案卷不回
潮」，本块答第三问：「恢复路径的契约还成立吗」——杀掉它看会不会
自己爬起来。原则与 touch-in 同源：**故障用业务自己的合法入口制造**
（字节注入/会话退出），不开后门、不追进程树。

### 沙箱观测三铁律（2026-08-27 pid 侦察战实锤）

判 na 主进程死活时：
1. `pgrep -f <名>` 在本信箱体系内**必自匹配**（调用方命令行含关键
   字），抓到的多半是自己——禁用作判据；
2. `/proc/<na.pid>/` 对 sshd 会话**不可见**（SELinux 同 uid 异类别
   隔离；ps 也看不到主进程本体，只见其子进程 ppid 悬挂）——扫 /
   proc 找不到 ≠ 死了；
3. 唯一可靠活性判据 = **`kill -0 $(cat na.pid)`**（内核信号权限检
   查，不受可见性影响）。SIGURG 探针（§十三①）因此恒可用。

### 探针 PIN-rehatch：会话死亡自动重孵契约

恢复链（代码事实）：shell 退出 → master 读端 EIO → waitpid 收尸 →
`SessionEvent::Exited` → `on_slot_dead`（health.dead +
session_deaths 计数 +1）→ 活跃方且未重试过 → 自动 respawn 一次 →
横幅「[kfm-na: local 会话断线，已重连 = 新 shell…]」喂进终端。

判卷四步（纯闸门，零核心改动）：
```
before=$(stats: session_deaths)
na-type 'exit\r'                    # 制造故障
轮询 stats: session_deaths ≥ before+1（10s 上限）
na-text 含「已重连 = 新 shell」且再注 echo 回显活着
```
exit 码 0 = 重孵契约在；超时 = 恢复路径病（用户视角：卡死不回来）。

## 一、页面骨架（三层目录在配置卡的落地）

- **标签栏（大类）**：系统管理 |（未来追加 API/角色/工具/session/脚本…）
- **下池（子目录选择）**：当前大类的子目录列表，聚焦行即选中
- **上池（二级选项）**：聚焦子目录的选项集 + 顶部联动下拉框
- **三级**：点击需要展开的二级选项 → 全屏页承载三级框

## 二、第一大类「系统管理」——服务器配置（2026-09-13 用户定方向）

### 2.1 背景与现状（诚实清单）

- 远程会话 = ws 连 `127.0.0.1:8021`（conn.rs ConnConfig 默认），
  隧道由 **Termux autossh** 持有（-L 8021 / -R 8022 / -R 8024 等）
- **2026-09-13 NA 自持通道已实证**（state.md 当日条）：
  沙箱 OpenSSH 客户端 + `$PREFIX/bin/na-tunnel.sh` 看守，
  **9021 正连**（NA→kfmv4）、**9022 反连+调试**（服务器直达 NA sshd）
  双向全通。Termux 依赖进入可退役状态
- **2026-09-19 隧道收归 na 原生**（用户拍板，取代 russh 提案）：
  `src/tunnel.rs` 内置 ssh 正连看门狗——启动即 spawn L3 prefix 的
  `ssh -N -L 9021:127.0.0.1:8021`（servers.json 的 ssh/tunnel 字段
  终于有消费者），单线程 1s 滴答探活 + 退避重拉（0/2/5/10/30s 封顶），
  状态出 `TunnelSnap`（连接/服务插件卡与断线状态卡的唯一数据源）。
  **让位/接管语义**：本地口被占且能连通（Termux 隧道还在）→
  ExternalUp 不抢，30s 复查；外部一断下一拍自持接管。
  **-R 9022 反连 2026-09-21 起 na 自持**（用户拍板「9022 我们
  自己的推送路径」）：v1 曾划给 Termux 维护——Termux 休眠冻结
  = 推送全瘫一整天实录；并进自持隧道后看门狗双腿（BAR-117）
  一并维护，na 活着反连就在。`-R 127.0.0.1:{remote_port}:
  127.0.0.1:8024` 显式绑回环：不新增公网暴露面（2026-09-01
  红线）；远端冲突时 ExitOnForwardFailure 整路死 = 看门狗
  知情重拉，不静默裸奔。
  na-tunnel.sh 脚本退役为手动兜底。
  **2026-09-20 可视化面落地（连接/服务卡 v1，用户立项）**：解析页
  第二张二级卡（纵排在 tmux 卡下），`src/ui/conn_card.rs`——卡头
  「连接 · 状态词」（自持在线/外部借用/连接中/退避 ×N/未启动，
  `tunnel::state_word` 唯一文案源）+ 四字段行（目标/本地口/重拉/
  错误）+ 分隔线 + [重连] 钮（`tunnel::request_reconnect`：杀娃、
  退避清零、下一拍立即重拉）。数据 = tunnel.rs 全局快照直读
  （supervisor 写、卡读，免穿 App plumbing）；TunnelSnap 加 epoch
  维进解析槽烘焙 sig——隧道状态翻转自动重烘，漏维 = 鬼影。几何：
  tmux 卡按 `conn_card::INSET_EXTRA`（= 卡间距 + 卡实高，同源钉死）
  预留底部带，涂装/命中/滚动五处调用点同加——眼手同尺。
- 会话切换：Ctrl-]（`\x1d`）在 android_app.rs UI 层拦截，双槽互换
  （本地 PTY ⇄ 远程 ws），写死

### 2.2 字段（用户 2026-09-13 列示）

每服务器条目：名称、服务器 IP、端口、用户、**密钥所在地址**、
**密码（空 = 密钥登录）**、**绑定切换快捷键**（未来多设备时每服务器
独立绑定，直达切换）。

全局项：**默认终端**（本地 / 某服务器）、**切换快捷键修改**。

### 2.3 目录映射（三层宪法套用；2026-09-13 二版修订，用户拍板）

- 下池（子目录）= 系统管理大类的子目录列表——**目前仅一行
  「系统管理」**（服务器配置；用户拍板：服务器列表**不进下池**）
- 上池（二级选项）= 服务器配置表单（kfmv4 API 卡模式）：
  - 第 1 行「默认服务器」**下拉框**——选项 = 本地终端 + 服务器池；
    换选 = 写 terminal.json `defaultSession` 落盘 + **活跃会话立即
    联动翻到对应槽**（2026-09-21 用户拍板：双槽保活 + replay 补屏，
    切回还是原样；纯核 = `DefaultSession::session_name`），
    下方服务器字段联动刷新
  - 第 2 行「服务器切换」= 全局切换快捷键（v1 只读展示 Ctrl+]，
    编辑走三级页 = v1b，宪法 §六 组合键录入控件）
  - 之下 = 下拉选中服务器的字段三级框（名称/IP/端口/用户/密钥
    地址/密码/wsUrl，v1 只读；选本地终端时无字段，上池占位）
- 三级全屏页 = 需要展开的字段编辑（候选：快捷键录入——修饰键下拉
  + 键名手填，宪法 §六 组合键录入控件条款）

### 2.4 切换行为决策（2026-09-13 用户拍板）

- **会话切换轮换环废弃**：AI 面板（光球召唤）**不参与**任何会话
  切换轮换；多服务器也不做轮转
- 改为：**全局切换键**（默认 Ctrl-]，本地 ⇄ 默认服务器）+
  **每服务器独立绑定快捷键**（设置里新增服务器时绑定，直达）
- 待拍板：多设备并存时全局切换键在「本地⇄默认服」还是
  「本地⇄最后活跃服」之间切——实现前用户定
- 切换键录入 = 手填，不做捕获（宪法 §六 组合键录入控件）
- **切换即刷新（BAR-124，2026-09-21 用户拍板）**：切换时对端强制
  全屏重画——resize 抖动（先 rows-1、120ms 后归位，两次净变化 →
  SIGWINCH）。同尺寸 Resize 补发是白发（净变化为零内核不发信号）；
  静默待机 replay 为空时无此抖动 = 整屏对端残影。已知边界：raw
  shell 无重画协议只能重印提示行；每会话网格快照是根治欠账（挂账）
- **切换换模式账 + 清屏（BAR-125，2026-09-21 用户拍板）**：切出存
  终端模式快照（鼠标上报/alt-screen/应用光标/bracketed paste），
  切入复位受管模式 + 清屏（「切换后直接自动清屏」）+ 恢复切入方
  快照。不换账 = tmux 鼠标模式泄漏到本地 shell，滑手势变 SGR 滚轮
  乱码。每会话网格快照（内容级）仍是挂账根治，本件只治模式层

### 2.5 数据模型（providers.json 模式复刻）

`servers.json`（app 私有目录，JSON 数组，宽容缺省）：

```json
[{
  "id": "main", "name": "阿里云主服",
  "ssh": { "host": "8.145.46.182", "port": 22, "user": "root",
           "keyPath": "…/files/usr/etc/ssh/id_ed25519", "password": "" },
  "tunnel": { "localPort": 9021, "remotePort": 9022 },
  "wsUrl": "ws://127.0.0.1:9021/ws", "command": null,
  "hotkey": { "mod": "ctrl", "key": "]" }
}]
```

`terminal.json`（全局）：`defaultSession`、`switchHotkey{mod,key}`。

- 密码空 = 密钥登录；文件在 app 沙盒私有目录（v1 可接受，
  未来 Android Keystore 加密另立项）
- **通联端口 = 工程参数，JSON 可设、UI 不摆**（2026-09-13 用户
  问、agent 建议、同日报价确认方向）：两端口本质不同——
  `localPort`（正连出口）绑在**手机本地**，同设备同时只活一条
  隧道时换服务器照用不撞，多服务器同连才需错位；`remotePort`
  （反连入口）绑在**服务器本地**，标识的是「这台设备」，撞口
  只发生在「多设备连同一服务器」或「同设备对同服务器双连」。
  分配规则：**每设备占 10 口段**——本机 9020 段（9021/9022），
  第二台设备 9030 段，以此类推；撞段改 JSON 一个数即解围。
  UI 不出端口项（防隧道活着时被改出事故）

## 三、第二大类「终端设置」（2026-09-24 用户拍板「滚动的像素级」）

### 3.1 定位与目录映射

下池第二行「终端设置 / 滚动行为」（focus 1；focus 0 = 系统管理
服务器配置不变）。上池首行 = 「像素级滚动」下拉（复用单下拉机制）：

- **关（行级保底）——默认**：触摸滚动照旧 TouchScroll::moved 行级
  通道（余数挂账整行提交），行为与历史版本逐格等价。这是降级
  保底：新机制出现意外随时切回，不许删。
- **开（像素级实验）**：触摸滚动走 moved_px 不取整通道，零头进
  分数视口（TermView::scroll_frac_px，带符号 px）。

### 3.2 分数视口契约（实现单源 src/termview.rs）

- alacritty 网格只存整数行；滚动零头（scroll_frac_px）在渲染/合成
  期补——与键盘 kb_frac 同套路。正零头 = 往历史（内容下移），顶缘
  多收 line=-1；负零头 = 往最新（内容上移），底缘多收
  line=screen_lines。
- 钳制：offset=0 不许负零头（贴底之下没有更新的行）；
  offset≥history 不许正零头（历史顶之上没有更老的行）。拨关
  清亚行零头（画面回整行，不残留亚行态）。
- 收集路径双缘多收行（softbuffer render_into / GPU
  collect_gpu_cells 一把尺）；GLES 合成期实例平移
  dy - kb_frac + scroll_frac，scissor 带 (顶带内缘, 内容底沿)。
- tmux 全屏（mouse_report_active）协议无像素概念：像素车道下走
  **外置视口浏览态**（§3.5）；行级保底车道照旧 SGR 滚轮事件。
- 一次触摸内不换道：通道分流发生在两次触摸之间（设置页点开关）。

### 3.5 外置视口浏览态（2026-09-25 用户拍板「跟终端同款的像素级
滚动」——tmux 滚轮一次闪 5 行的根治）

**力学**：tmux attach 下屏上以外的内容在服务器 tmux 手里，本端网格
只有可见行——「平移视口」成立的前提是手里有全部内容。滚轮 tick 路
的本体病灶 = tmux 默认绑定 `WheelUpPane → send-keys -X -N 5
scroll-up`（服务器 list-keys 实证），1 tick 跳 5 行，跟手换算再细
也救不了对端的 5 倍率。

**契约**（实现单源 src/termview.rs browse 族 + android_app 接线）：

- **触发**：像素车道 + mouse_report_active + 有附着会话
  （cur_attached Some）的拖动起手 → endpoint_exec 发
  `tmux_ctl::cmd_capture`（capture-pane -p -e -S -，目标 `'=name:'`
  精确会话+活动窗格，尾带 KFM_CAP_OK 成功标记——BAR-152：tmux
  报错文本与快照同走 stdout，capture_strip_marker 验收无标记不
  许进浏览态）。
  非 tmux 附体（裸 TUI 无快照源）= 滚轮翻译旧路不动。
- **快照**：enter_browse 喂独立 Term（与 live 同网格尺寸，切入零跳
  动；超屏行沉 browse scrollback = 可滚里程；尾补 ?25l 藏快照光
  标——光标是 live 的发言权）。抓取往返期手指位移挂账
  （browse_pending_px），落地瞬间一并补滚——起手零丢失。
- **浏览期**：渲染/滚动/命中/选择/导出全切 active_term（=快照），
  与终端像素滚动同一套 scroll_px/分数视口机制；永不发滚轮 tick。
  live term 照常被会话泵喂——退出即回最新，零追赶。浏览期内容冻
  结（copy-mode 同款语义）；长按选择/复制在快照上照常用。
- **退出**（任一即退，退出 = 回 live 最新）：①击键（route_input
  头）②会话切换 Ctrl-] ③attach 切换 ④resize（resize_cells 防御
  清快照）⑤对端鼠标上报消失（about_to_wait 轮询——tmux 退出/脱离
  /重孵清场自愈）。退出清分数零头（视口态换源归零）。
- **降级保底铁律不变**：设置页切「关（行级保底）」= 整条快照路
  不触发，滚轮翻译照旧。

**判卷**：termview_spec 浏览态三钉（快照切换与像素滚动/resize 清
快照/光标藏起来），变异两咬全中（enter 不喂快照、exit 不清零头
均即红）；tmux_ctl_spec cmd_capture 钉（'=' 精确匹配/-e 保色/
-S - 全史）。C 档实机判卷点：拖动起手 ~300ms 后切入浏览（抓取往
返），之后 1:1 像素跟手滚全史；击键即回 live 最新。

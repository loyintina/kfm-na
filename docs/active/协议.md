# ws 协议（客户端视角）

> 2026-08-13 立。真相源：kfmv4/src/server/ws-server.ts handleMessage +
> terminal-pty.ts + ws-channel.ts 封套。本文件是客户端对接面的登记，
#  实现 = src/protocol.rs（考题 tests/protocol_spec.rs 锁死行为）。

## 封套

```json
{"type": "<消息类型>", "payload": {...}, "timestamp": <epoch ms>}
```

字段名一律 camelCase（`sessionId`——写 snake_case 就是哑弹，考题钉死）。

## C→S（客户端发）

| type | payload | 说明 |
|------|---------|------|
| terminal-open | `{cwd?, command?, tag?}` | 开 PTY 会话；command 空 = 交互 shell；全空 payload 为 `{}` |
| terminal-input | `{sessionId, input}` | 注入按键（含 ANSI 序列） |
| terminal-resize | `{sessionId, cols, rows}` | cols/rows 为数字 |
| terminal-close | `{sessionId}` | 杀会话 |

## S→C（客户端收）

| type | payload | 说明 |
|------|---------|------|
| terminal-opened | `{sessionId, tag?}` | tag 可能缺省（undefined） |
| terminal-output | `{sessionId, data}` | PTY 字节流，含 ANSI/中文，一个字符不许变 |
| terminal-exit | `{sessionId, code}` | code 为数字（严格，字符串拒收） |
| error | `{message}` | 如 PTY spawn failed |
| ping | `null` | 30s 心跳（应用层，另有协议级 ping/pong） |
| 其他（ack/snapshot/tmux-*…） | — | 归 Unknown，前向兼容收纳 |

## 健壮性约定（考题钉死）

- 畸形 JSON / 缺 type / 必填字段缺失 → Err，不得 panic
- 多余字段（服务端将来扩字段）→ 容忍
- timestamp 仅编码时生成（>0），解码忽略

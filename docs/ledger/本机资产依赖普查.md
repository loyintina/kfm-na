> 「依赖什么 / 干净克隆表现（红/跳过/静默降级）/ 归桶」，结论分
> **治本清单**与**基建清单**两桶。模子 = 0017 §二表格。

## 方法

- **静态扫面**：全仓 grep 候选面——`assets/fonts/local/*`、`/dev/shm`、
  绝对路径 `/root/kfmv4` 与 `/root/.kfm`、hostname/IP/端口、环境变量、
  `#[ignore]` 钉的依赖自述。
- **普查机实证**：挪走 `assets/fonts/local/`（唯一已归口的本机资产）后
  `cargo test --workspace -- --no-fail-fast`，与有字体全量绿对照——
  红的就是字体依赖，绿的就是鲁棒。
